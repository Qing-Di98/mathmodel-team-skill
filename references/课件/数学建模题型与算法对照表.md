常用模型与算法
说明： 1. 本表涵盖数学建模竞赛70+种常用模型算法，按11大类题型分类 2. 同一问题可能有多种模型选择，应根据数据特点、题目要求和计算资源综合判断 3. 推荐学习路径：优化类(LP/IP) → 评价类(AHP/TOPSIS) → 预测类(灰色/ARIMA) → 分类聚类 → 图论网络 → 深度学习 4. Python库为常用工具，实际使用时可根据需要选择替代方案
