## 课件内容速览（便于快速定位）

### 数据处理与预测模型（2026-08 新增）

- **1数据预处理理论基础**：标准流水线（探查→去重→缺失修复→异常修正→插值补全→标准化→建模→精度评估）；四类脏数据（缺失/异常/重复/格式）判定与处理原则；缺失值三方案（删除/统计量填充/插值，小样本时序**严禁删除**）；3σ vs IQR（含极端值必选 IQR）；线性插值/三次样条（**仅内插、禁止外推**）；一元/多元线性回归（最小二乘、R²/MSE/MAE）；**四大预测模型选型表**（插值/一元回归/多元回归/GM(1,1)：样本量、预测能力、优劣）；真题评分点拆解。
- **2ARIMA&SARIMA零基础全解**：两大场景判定（无周期→ARIMA、有月度/季度/年度固定周期→SARIMA）；ARIMA(p,d,q) 三参数含义；ADF 平稳性检验（P<0.05 平稳）；**国赛 7 步标准流程**（可视化→ADF→定 d→ACF/PACF 或 AIC/BIC 定 p,q→训练→残差白噪声检验→拟合+外推）；截尾/拖尾判参规则；ARIMA(1,1,1) 万能兜底；SARIMA(p,d,q)(P,D,Q)m（月度 m=12/季度 m=4/周度 m=7，万能组合 (1,1,1)(1,1,1)m）；**ARIMA/SARIMA/GM(1,1) 选型对比表**；六类常见错误（小样本用 ARIMA、有周期用 ARIMA、跳过 ADF、用 ARIMA 补缺失、不做残差检验、高阶参数）；满分论文话术。

- **3灰色GM(1,1)完整数学推导、残差检验、封装类代码**：GM(1,1) 适用条件（小样本 3≤n≤15、单变量、短期 3-6 期预测；n≥20 用回归/ARIMA；a>0.5 模型作废；严禁长期预测/多变量直套）；AGO 累加→紧邻均值→微分方程→最小二乘→IAGO 还原五步推导；后验差检验（方差比+小误差概率定级）；封装类 `GM11` 代码（可直接复制）；8 个月游客量真题精讲；提分拓展（残差修正 GM(1,1)、灰色+线性回归组合）。
- **GM(1,1)灰色预测模型在农作物年产量预测中的应用**：2019-2023 年 5 组产量完整数值例题——AGO/紧邻均值/参数求解/时间响应函数/累减还原全步骤带数值，历史拟合误差极小，2024/2025 外推预测，后验差一级精度，附论文直接可用总结句。
- **数模国赛聚类分析（K-Means）**：聚类定位（无监督辅助分析，不预测不优化）；适用场景；选型（**不推荐层次聚类/模糊聚类/DBSCAN**，国赛满分选型 K-Means）；五步流程（Min-Max 标准化→肘部法则定 K→初始化→迭代归类→可视化+特征解析）；四种高阶用法（先聚类后分层 TOPSIS 评价、聚类降噪、分区域差异化建模、方案分级）；扣分点（未标准化/无肘部图/只画图不解读/把聚类当预测/不联动后续模型）；标准章节段落。

### 优化模型与评价模型（2026-08 新分类）

- **优化模型 + 评价模型**：优化解决"该做什么"、评价解决"哪个更好"，常组合使用（先评价筛候选、再优化分配）；优化三要素（决策变量/目标函数/约束）；LP 标准形式、IP 与 0-1 规划、MILP；模型选取逻辑。
- **AHP**：层次结构、判断矩阵、一致性检验（CR<0.1）、权重计算。
- **TOPSIS**：指标同向化/归一化、正负理想解、贴近度排序。
- **bigM**：大 M 法线性化（分段/逻辑约束转化）。
- **PuLP代码**：Python PuLP 建模模板与求解。
