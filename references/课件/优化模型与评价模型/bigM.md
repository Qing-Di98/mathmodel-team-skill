big-M 专题:开关约束
连续变量 + 0-1 变量怎么协同
2024 C 题种植场景
一、决策什么
想象你承包了一片农场,手里有 30 块地,仓库里有 15 种作物的种子。现在要决定明年这一整年怎么种,让全年利润最大。
每块地 + 每种作物,你都要回答两个问题:
第一问:这块地到底种不种这种作物?(是非题,只有"种"或"不种")
第二问:如果种,种多少亩?(可以是 3.7 亩,可以是 5.2 亩,是个连续的数)
这两个问题不能合并成一个变量表达——因为一个是选择,一个是数量,性质完全不一样。所以要引入两种决策变量。
二、两种决策变量:x 和 y
xij = 第 i 块地种作物 j 的面积(亩) ← 连续变量,≥ 0 yij = 第 i 块地是否种作物 j ← 0-1 变量 种=1, 不种=0
为啥非要两个变量?一个不够吗?
直接用 xij 一个不就行了?x=0 就代表不种,x>0 就代表种。看似合理,但一旦题目里出现"约束和是否种植有关"的条款,一个变量就不够用了。
题目通常会加一条:每块地一年最多种 3 种作物(因为要考虑轮作)。这条约束只用 xij 根本写不出来——因为面积本身表达不了'种了几种',x=0.001 也是种,x=5 也是种。"
有了 yij 就好写了:
y_i1 + y_i2 + y_i3 + ... + y_in ≤ 3 (0/1 变量之和,就是"这块地种了几种作物")
通俗理解: 铁律——是非题用 0-1 变量,数量用连续变量,两个同时用,这是数模建模里最常见的搭配。
三、x 和 y 怎么协调?
如果求解器算出来 yij = 0(说不种),但同时 xij = 5(种了 5 亩),就自相矛盾了吗?所以我们必须加一条约束,把 x 和 y 绑在一起。
我们想表达的逻辑是:
if y_ij == 0: x_ij = 0 ← 不种,面积必须是 0 else: # y_ij == 1 x_ij 可以是任何 ≥ 0 的数 ← 种,面积随便
但线性规划不允许写 if-else,只能写不等式。怎么把这段 if-else 翻译成一条不等式?
四、big-M 技巧
xij ≤ M × yij ← M 是一个很大的正数,比如 10000
分两种情况看这条式子在干嘛
情况 1: yij = 0 (不种)
约束变成: xij ≤ M × 0 = 0 又因为: xij ≥ 0 夹逼出来: xij = 0 ← 不种,面积一定是 0 ✓
情况 2: yij = 1 (种)
约束变成: xij ≤ M × 1 = 10000 等于"没有约束",xij 会被别的约束(比如地块总面积)去限制 ✓
一条不等式,把 if-else 表达出来了。这就是 big-M 的精髓——用一个大数当"开关放大器",y 是 0 就把 x 压到 0,y 是 1 就把上界放到无穷大。
五、M 到底取多大?
这是学生最爱问的问题。答案是"够大但不能太大"。
M 太小的坑:
如果写 M=3,那 y=1 时约束变成 x ≤ 3——就算这块地真实是 100 亩,你也只能种 3 亩,合理的方案被卡死了。这叫'M 取小了误伤'。
M 太大的坑:
如果写 M=10^9(十亿),数值上会不稳定,求解器可能算得极慢,甚至出现浮点误差,y 明明该是 0 却算成 0.0001,结果偏差很大。
实战经验:
M = "这个变量在物理上能达到的最大值" + 一点余量
六、把整套约束串起来看一遍
目标: max Σ Σ (单产j × 单价j - 成本j) × xij 约束: Σj xij ≤ areai ← ① 每块地总种植面积不超地块面积 xij ≤ M × yij ← ② big-M:不种就一定是 0 亩
（xij = yij × |xij |）
Σj yij ≤ 3 ← ③ 每块地最多种 3 种(可选) xij ≥ 0 ← ④ 面积非负 yij ∈ {0, 1} ← ⑤ 是非题
5 条约束协同工作——第一条管物理上限(地就这么大),第二条把 x 和 y 绑在一起(不种就是 0),第三条控制种植种类不超 3 种(轮作要求),第四条第五条管变量本身的合法范围。缺一不可。
七、什么时候用
通俗理解: big-M 是数模里最常见的"开关约束"。想说"只有选了才允许干",就写:实际动作 ≤ M × 选择变量。
以下题型可以套 big-M:
"要不要开分店(0-1) + 开了之后卖多少(连续)"
"要不要建工厂(0-1) + 建了之后生产多少(连续)"
"要不要投项目(0-1) + 投了投多少钱(连续)"
"要不要在这块地种(0-1) + 种多少亩(连续)" ← 就是 2024 C 题
