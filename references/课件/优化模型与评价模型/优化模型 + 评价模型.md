优化模型 + 评价模型
优化模型解决'该做什么',评价模型解决'哪个更好'——真实数模题里往往两个一起用:先用评价模型给候选方案打分排序,再用优化模型选出最优组合。
举个例子:
2024 C 农作物种植:哪种作物种在哪块地 → 优化模型(MILP)。
2023 B 优秀节能建筑评价:多个候选建筑排序 → 评价模型(AHP + TOPSIS)。
实际题目常常两个都用:先评价筛出高分候选,再优化决定资源分配。

优化模型理论
线性规划、整数规划、MILP
一、什么是"优化模型"
优化模型的核心是在一堆约束下,找一组决策变量,让某个目标最大(或最小)。
三要素:决策变量 · 目标函数 · 约束条件
任何优化题都能拆成这三块,拆完题就写好一半了。
三要素 写题时问自己的问题 ──────────────────────────────────────── 决策变量 x 我到底能"选"什么?(能自己定的量) 目标函数 f(x) 我想让什么最大/最小?(利润、成本、时间、误差) 约束条件 g(x) 有什么"不能超过"或"必须满足"的?
通俗理解: 记住这个顺序:先问"能选什么",再问"想要什么",最后问"不能违反什么"。按这个顺序想,再复杂的题都能拆得清清楚楚。
生活例子:周末去超市
周末去超市,兜里 100 块,想买尽可能多的种类,又要够全家吃一周。
决策变量:每样商品买多少袋 → x米、x菜、x肉、x水果 目标函数:营养分数最大化 → max Σ 营养i × xi 约束条件: 总花费 ≤ 100 元 每样至少买 1 袋 数量必须是整数(不能买 2.3 袋米)
二、线性规划(LP)
什么叫"线性"
目标函数和约束条件里,变量都只是'加加减减、乘个常数'——没有平方、没有相除、没有 sin cos,就叫线性。
线性 : 3x + 5y ≤ 100 非线性 : x² + y ≤ 100 (有平方) 非线性 : x × y ≤ 100 (两变量相乘) 非线性 : sin(x) ≤ 100 (有三角函数)
标准形式
max (或 min) c₁x₁ + c₂x₂ + ... + cₙxₙ s.t. a₁₁x₁ + a₁₂x₂ + ... ≤ b₁ a₂₁x₁ + a₂₂x₂ + ... ≤ b₂ ... x₁, x₂, ..., xₙ ≥ 0
通俗理解: s.t. 就是 "subject to"(受约束于)的缩写，写题时用 s.t.
经典例子:工厂生产问题
题目:某工厂做 A、B 两种产品,已知:
单位工时 单位材料 单位利润 产品 A 1 h 4 kg 6 元 产品 B 2 h 3 kg 5 元 每天工时上限 8 h,材料上限 12 kg。 问:每天各生产多少 A、B,利润最大?
三步建模
第 1 步:决策变量 x₁ = 每天生产 A 的数量 x₂ = 每天生产 B 的数量 第 2 步:目标函数 max Z = 6x₁ + 5x₂ (总利润) 第 3 步:约束条件 s.t. x₁ + 2x₂ ≤ 8 (工时不超) 4x₁ + 3x₂ ≤ 12 (材料不超) x₁, x₂ ≥ 0 (非负)
这就是完整的 LP 建模。至于怎么解——后续讲解会用 PuLP 求解。
三、整数规划(IP)与 0-1 规划
整数规划(IP)
决策变量必须是整数——因为现实里'半个人'、'0.7 台机器'没意义。
在 LP 基础上加一条:
x₁, x₂, ..., xₙ ∈ ℤ⁺ (非负整数)
0-1 规划
最特殊的整数规划——变量只能取 0 或 1。通常用来表达'选还是不选'、'做还是不做'这种二选一决策。
应用场景 变量含义 ───────────────────────────────────────── 项目选址 xi = 1 表示在第 i 处建仓库,0 不建 背包问题 xi = 1 表示装第 i 件物品,0 不装 指派问题 xij = 1 表示第 i 人做第 j 件事
例子:0-1 背包
5 件物品放进容量 10 的包,每件重量、价值不同,总重量不超,求总价值最大。
xi ∈ {0, 1}, i = 1,...,5
max Σ vi × xi s.t. Σ wi × xi ≤ 10
通俗理解: xi ∈ {0, 1} 就是 0-1 变量的写法,阅卷老师一眼就知道你用了 0-1 规划。
四、混合整数规划(MILP)
MILP = Mixed Integer Linear Programming。'混合'的意思是:一些变量是连续的、一些是整数或 0-1。这是数模里最常用的形式,几乎所有优化题都能套上。
典型场景
例:农作物种植(2024 C) 连续变量:每块地种某作物的面积 xij(可以是 3.7 亩) 0-1 变量:该块地是否种某作物 yij(种=1,不种=0) 目标: max 总利润 约束: 每块地总面积 ≤ 该地块面积 xij ≤ M × yij (只有 y=1 时才允许 x>0) xij ≥ 0, yij ∈ {0, 1}
通俗理解: "xij ≤ M × yij" 这个技巧叫 "big-M",用一个大数把两个变量绑在一起，数模里用得极多。
五、什么时候用哪种?
决策变量类型 用哪种 全部连续(面积、重量、时间) LP(线性规划) 全部整数(人数、件数) IP(整数规划) 全部 0/1(选/不选、做/不做) 0-1 规划 又有连续又有 0/1 MILP(最常用)
记忆口诀
能选什么写变量,想要什么写目标,不能违反写约束。连续用 LP,离散加整数,选择用 0-1,混着就 MILP。
六、常见陷阱(阅卷会扣分)
陷阱 1:忘写非负约束(x ≥ 0),PuLP 默认非负,但写论文时必须写全。
陷阱 2:目标写反了,题目要最小成本你写了最大成本。审题时圈出关键词。
陷阱 3:约束条件不完整,漏了资源上限或需求下限。列清单核对。
陷阱 4:整数约束没加,导致解出小数,现实无法实施。
陷阱 5:big-M 取值过大导致求解慢,一般取一个合理的上界即可。
PuLP 现场演示
三个小例子:LP、0-1 背包、指派问题
例子 1:工厂生产问题(线性规划)
上节讲义里的'A、B 两种产品'那道题,用 PuLP 求解
代码逐行讲
from pulp import * # ① 创建问题:目标是最大化 prob = LpProblem("工厂利润", LpMaximize) # ② 定义决策变量(非负) x1 = LpVariable("A产品数量", lowBound=0) x2 = LpVariable("B产品数量", lowBound=0) # ③ 写目标函数 prob += 6*x1 + 5*x2 # ④ 写约束条件 prob += x1 + 2*x2 <= 8, "工时约束" prob += 4*x1 + 3*x2 <= 12, "材料约束" # ⑤ 求解 + 打印 prob.solve() print("A =", x1.varValue, ", B =", x2.varValue) print("最大利润 =", value(prob.objective))
预期输出:
A = 1.8 , B = 1.6 最大利润 = 18.8
A 生产 1.8 单位、B 生产 1.6 单位,利润 18.8 元。"
注意 A、B 都是小数——如果题目要求整数,在 LpVariable 里加一个 cat='Integer' 就变成整数规划。
例子 2:0-1 背包问题
5 件宝物,容量 10 的背包,每件重量、价值不同。装还是不装?用 0-1 规划。
weights = [2, 3, 4, 5, 6] values = [3, 4, 5, 8, 9] n = len(weights) prob = LpProblem("背包", LpMaximize) # 关键:cat="Binary" 就是 0-1 变量 x = [LpVariable(f"x{i}", cat="Binary") for i in range(n)] prob += lpSum(values[i]*x[i] for i in range(n)) prob += lpSum(weights[i]*x[i] for i in range(n)) <= 10 prob.solve() for i in range(n): print(f"物品{i}:{'装' if x[i].varValue==1 else '不装'}") print("总价值 =", value(prob.objective))
预期输出:
物品0:不装 物品1:装 物品2:不装 物品3:装 物品4:不装 总价值 = 12.0
通俗理解: lpSum(...) 是 PuLP 的求和函数,和 Python 内置 sum 一样,但对大规模问题更快、写起来更简洁。
例子 3:指派问题(有实际竞赛味)
3 个员工做 3 件事,每个人做每件事的效率都不同。每人只能做 1 件,每件只能派 1 人,如何指派让总效率最高?
# 效率矩阵:行=员工,列=任务 eff = [[9, 2, 7], [6, 4, 3], [5, 8, 1]] prob = LpProblem("指派", LpMaximize) # x[i][j] = 1 表示员工 i 做任务 j x = [[LpVariable(f"x_{i}_{j}", cat="Binary") for j in range(3)] for i in range(3)] # 目标:总效率最大 prob += lpSum(eff[i][j]*x[i][j] for i in range(3) for j in range(3)) # 约束 1:每人只做 1 件 for i in range(3): prob += lpSum(x[i][j] for j in range(3)) == 1 # 约束 2:每件只 1 人做 for j in range(3): prob += lpSum(x[i][j] for i in range(3)) == 1 prob.solve() for i in range(3): for j in range(3): if x[i][j].varValue == 1: print(f"员工{i} → 任务{j}(效率{eff[i][j]})")
预期输出:
员工0 → 任务0(效率9) 员工1 → 任务2(效率3) 员工2 → 任务1(效率8) 总效率 = 20
这就是数模里的'指派问题'原型——只要'一一匹配'的场景都能用。比如'员工-任务'、'船-泊位'、'广告-时段'、'志愿者-赛道'。
这 3 个例子覆盖了 90% 的优化题写法: 1) 全连续变量 → LP,直接 LpVariable(lowBound=0) 2) 0/1 选择变量 → cat='Binary' 3) 二维匹配 → 双下标 x[i][j]
评价模型
AHP 层次分析 + TOPSIS 理想解
一、什么是"评价模型"
评价模型解决'多个方案怎么打分排序'的问题。核心矛盾就一个:有多个指标、每个指标重要性不同,怎么综合成一个总分?
两大关键动作
任何评价模型都在做两件事:
① 定权重:哪个指标重要?给它多少分量?—— AHP
② 合分数:所有指标加权算一个总分。—— TOPSIS
常常两个联合用:先用 AHP 算出权重,再用 TOPSIS 算最终得分。
生活例子
想买手机,预算 9000。看了 3 台候选,每台有价格、性能、外观、续航 4 个指标。
给"价格"打个高权重
给"外观"低权重
每台机在 4 个指标上打分
把 4 个分乘以权重加起来,谁高买谁
这就是评价模型。AHP 定权重,TOPSIS 算总分。
二、AHP 层次分析法
核心思想
AHP 的核心思想:人一次比较两个东西很容易,一次比较 5 个很难。所以我们让专家两两比较,再从这些比较里算出整体权重。
标度表(要背)
分值 含义 ────────────────────────────────── 1 两个同等重要 3 前者稍微重要 5 前者明显重要 7 前者强烈重要 9 前者极端重要 2,4,6,8 上述相邻分值的中间值 1/3, 1/5, ... 倒数,表示后者重要
假设买手机,对 4 个指标做两两比较,写出判断矩阵:
价格 性能 外观 续航 价格 [ 1 2 5 3 ] 性能 [ 1/2 1 3 2 ] 外观 [ 1/5 1/3 1 1/2 ] 续航 [ 1/3 1/2 2 1 ]
解题步骤(4 步)
步骤 1:按列归一化
每一列先求和,再让每个元素除以列和。
第 1 列和 = 1 + 1/2 + 1/5 + 1/3 = 2.033 第 2 列和 = 2 + 1 + 1/3 + 1/2 = 3.833 第 3 列和 = 5 + 3 + 1 + 2 = 11.000 第 4 列和 = 3 + 2 + 1/2 + 1 = 6.500 归一化矩阵: 价格 [ 0.492 0.522 0.455 0.462 ] 性能 [ 0.246 0.261 0.273 0.308 ] 外观 [ 0.098 0.087 0.091 0.077 ] 续航 [ 0.164 0.130 0.182 0.154 ]
步骤 2:按行求平均 → 得到权重向量 w
w_价格 = (0.492+0.522+0.455+0.462)/4 = 0.483 w_性能 = (0.246+0.261+0.273+0.308)/4 = 0.272 w_外观 = (0.098+0.087+0.091+0.077)/4 = 0.088 w_续航 = (0.164+0.130+0.182+0.154)/4 = 0.157 → w = [0.483, 0.272, 0.088, 0.157]
这就是 AHP 算出的 4 个指标的权重——加起来正好等于 1。
步骤 3:算一致性指标 CI(检查你的判断矩阵合不合理)
CI = (λ_max - n) / (n - 1) 其中 λ_max = A × w 除以 w 后取平均 对本例:λ_max ≈ 4.05,n = 4 CI = (4.05 - 4) / 3 ≈ 0.017
步骤 4:算一致性比率 CR
CR = CI / RI RI(随机一致性指标)查表:n=4 时 RI = 0.90 CR = 0.017 / 0.90 ≈ 0.019 判定标准:CR < 0.10 → 通过 ✓ CR ≥ 0.10 → 判断矩阵不合理,回去重新调数字
CR < 0.1 才算通过一致性检验。如果通不过,说明你两两比较时前后矛盾,比如你说 A>B、B>C,却又说 C>A,这时候要回去改矩阵。
RI 查表(常用值必记)
n 3 4 5 6 7 8 9 RI 0.58 0.90 1.12 1.24 1.32 1.41 1.45
三、TOPSIS 理想解逼近法
核心思想
TOPSIS 就一句话:离'最好方案'最近、离'最差方案'最远的,就是最优。哪怕不是每个指标都第一,但整体最贴近理想的,就是它。
TOPSIS = Technique for Order Preference by Similarity to Ideal Solution。中文可以翻译成"逼近理想解排序法"。
解题步骤(5 步)
延续买手机的例子:有 3 台候选,4 个指标,权重已由 AHP 算出。
权重 w = [0.483, 0.272, 0.088, 0.157] 原始数据: 价格(万) 性能(分) 外观(分) 续航(时) 手机 A 0.30 85 80 24 手机 B 0.50 95 90 30 手机 C 0.40 70 75 20
步骤 1:指标正向化(把"越小越好"转成"越大越好")
价格是'越小越好'的成本型指标,要先反过来变成'越大越好'。常用方法:用 (最大值 - 当前值) 或 (1 / 当前值)。
用"最大值 - 当前值"方法处理"价格": max_价格 = 0.50 价格_A' = 0.50 - 0.30 = 0.20 价格_B' = 0.50 - 0.50 = 0.00 价格_C' = 0.50 - 0.40 = 0.10 正向化后: 价格' 性能 外观 续航 手机 A 0.20 85 80 24 手机 B 0.00 95 90 30 手机 C 0.10 70 75 20
步骤 2:每列归一化(消除量纲差异)
归一化公式: zij = xij / √(Σxij²) 例如第 2 列(性能): 分母 = √(85² + 95² + 70²) = √22150 = 148.83 z_A2 = 85/148.83 = 0.571 z_B2 = 95/148.83 = 0.638 z_C2 = 70/148.83 = 0.470 4 列都做完,得到归一化矩阵 Z
步骤 3:乘权重 → 加权归一化矩阵 V
Vij = wj × zij
步骤 4:找正理想解 V⁺ 和负理想解 V⁻
正理想解 V⁺ = 每列取最大值 (最好方案) 负理想解 V⁻ = 每列取最小值 (最差方案)
步骤 5:算每个方案到 V⁺ 和 V⁻ 的距离,再算贴近度 C
D⁺i = √Σ (Vij - V⁺j)² (到正理想解距离) D⁻i = √Σ (Vij - V⁻j)² (到负理想解距离) Ci = D⁻i / (D⁺i + D⁻i) (贴近度,越大越好)
最后按 Ci 排序:C 越接近 1,就越贴近'完美方案'。这就是 TOPSIS 的最终排名。
四、AHP vs TOPSIS(什么时候用哪个)
需求 用哪个 ───────────────────────────────────────── 只想知道每个指标多重要(定权重) AHP 只想给候选方案打分排序(定分数) TOPSIS 既要定权重又要排序(最常见) AHP + TOPSIS 联用
完整流程(联用)
Step 1 拉出评价指标(专家会议 or 文献综述) Step 2 用 AHP 两两比较,算出权重 w ← 一致性 CR 必须 < 0.1 Step 3 收集候选方案在各指标上的数据 Step 4 用 TOPSIS 五步走,算出每个方案的贴近度 C Step 5 按 C 从大到小排序,就是最终推荐
考场上如果题目问'评价 / 排序 / 选优',先 AHP 定权重、再 TOPSIS 打分。
五、常见陷阱
AHP 判断矩阵前后矛盾 → 一致性 CR ≥ 0.1 → 必须重新调数字。
忘了正向化 → 成本型指标(价格、能耗)当"越大越好"处理,结果颠倒。
忘了归一化 → 不同量纲(万元 vs 时)直接加,权重被大数值吃掉。
主观权重与客观权重混用不清 → AHP 是主观,熵权法是客观,论文里要说清。

AHP:算权重
我们把讲义 04 里那个 4 阶判断矩阵直接搬进来,10 行代码算出权重和 CR。"
import numpy as np # 判断矩阵 A = np.array([ [1, 2, 5, 3 ], [1/2, 1, 3, 2 ], [1/5, 1/3, 1, 1/2 ], [1/3, 1/2, 2, 1 ], ]) # 步骤 1-2:归一化 + 求平均得权重 col_sum = A.sum(axis=0) # 每列求和 B = A / col_sum # 按列归一化 w = B.mean(axis=1) # 按行求平均 print("权重:", w.round(3)) # 步骤 3-4:算一致性 CR lam_max = (A @ w / w).mean() # λ_max n = len(A) CI = (lam_max - n) / (n - 1) RI = [0, 0, 0.58, 0.90, 1.12, 1.24, 1.32, 1.41, 1.45][n] CR = CI / RI print(f"λ_max = {lam_max:.4f}, CI = {CI:.4f}") print(f"CR = {CR:.4f} {'通过 ✓' if CR < 0.1 else '不通过 ✗'}")
预期输出:
权重: [0.483 0.272 0.088 0.157] λ_max = 4.0499, CI = 0.0166 CR = 0.0185 通过 ✓
关键三行:col_sum → 归一化 → 按行平均。这是 AHP 的核心动作,记住这个套路。
TOPSIS:排序
权重有了,现在给 3 台候选手机排序。TOPSIS 五步,每步一行代码。

def ahp_topsis(A, X, cost_cols): """A: 判断矩阵; X: 数据矩阵; cost_cols: 成本型列索引""" # AHP w = (A / A.sum(axis=0)).mean(axis=1) # TOPSIS X = X.astype(float).copy() for j in cost_cols: X[:, j] = X[:, j].max() - X[:, j] Z = X / np.sqrt((X ** 2).sum(axis=0)) V = Z * w D_p = np.sqrt(((V - V.max(0)) ** 2).sum(1)) D_m = np.sqrt(((V - V.min(0)) ** 2).sum(1)) C = D_m / (D_p + D_m) return w, C, np.argsort(-C) + 1 # 使用 w, C, rank = ahp_topsis(A, X, cost_cols=[0]) print("权重", w) print("贴近度", C) print("排名", rank)
