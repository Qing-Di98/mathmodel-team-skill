AHP 4 步
整个流程 4 步:
①【填矩阵】你两两对比 → 得到判断矩阵 A ②【算权重】对 A 做两步运算 → 权重向量 w ③【算矛盾】用 A 和 w 反算 λ_max → 得到 CI ④【判合格】CR = CI / RI 比 0.1 → 通过就用 w,不通过重填
先处理判断矩阵 A
价格 性能 外观 续航 价格 [ 1 2 5 3 ] 性能 [ 1/2 1 3 2 ] 外观 [ 1/5 1/3 1 1/2 ] 续航 [ 1/3 1/2 2 1 ]
读法回顾:A[i][j] = "第 i 行指标 相对于 第 j 列指标 的重要性"。
A[价格][性能] = 2 → 价格比性能重要 2 倍
A[外观][价格] = 1/5 → 外观比价格重要 1/5(反过来价格比外观重 5 倍)
目标:从这个矩阵反推出 4 个指标的权重。
步骤 1:按列归一化
第一小步:先算 4 个列和
"列和"就是把每一列的 4 个数字加起来。
第 1 列(价格列)的 4 个数是 1, 1/2, 1/5, 1/3。加起来:
1 + 1/2 + 1/5 + 1/3 = 1 + 0.5 + 0.2 + 0.333 = 2.033
第 2 列(性能列):2, 1, 1/3, 1/2
2 + 1 + 1/3 + 1/2 = 2 + 1 + 0.333 + 0.5 = 3.833
第 3 列(外观列):5, 3, 1, 2
5 + 3 + 1 + 2 = 11.000
第 4 列(续航列):3, 2, 1/2, 1
3 + 2 + 1/2 + 1 = 3 + 2 + 0.5 + 1 = 6.500
汇总 4 个列和:
列 1 = 2.033 列 2 = 3.833 列 3 = 11.000 列 4 = 6.500
第二小步:每个格子除以它所在的列和
第 1 列的 4 个格子全部除以 2.033,第 2 列的 4 个格子全部除以 3.833,以此类推。4 列独立做除法,不要串在一起。
第 1 列除以 2.033:
1 / 2.033 = 0.492 ← 价格行 1/2 / 2.033 = 0.5/2.033 = 0.246 ← 性能行 1/5 / 2.033 = 0.2/2.033 = 0.098 ← 外观行 1/3 / 2.033 = 0.333/2.033 = 0.164 ← 续航行 验证: 0.492 + 0.246 + 0.098 + 0.164 = 1.000
注意: 每列归一化后必然加起来等于 1。如果算出来不是 1,肯定是除法算错了,回去检查。
第 2 列除以 3.833:
2 / 3.833 = 0.522 1 / 3.833 = 0.261 1/3 / 3.833 = 0.087 1/2 / 3.833 = 0.130 验证: 0.522 + 0.261 + 0.087 + 0.130 = 1.000
第 3 列除以 11:
5 / 11 = 0.455 3 / 11 = 0.273 1 / 11 = 0.091 2 / 11 = 0.182 验证: 0.455 + 0.273 + 0.091 + 0.182 = 1.001
第 4 列除以 6.5:
3 / 6.5 = 0.462 2 / 6.5 = 0.308 1/2 / 6.5 = 0.077 1 / 6.5 = 0.154 验证: 0.462 + 0.308 + 0.077 + 0.154 = 1.001
第三小步:把 4 列拼回一张归一化矩阵
列1 列2 列3 列4 价格 [ 0.492 0.522 0.455 0.462 ] 性能 [ 0.246 0.261 0.273 0.308 ] 外观 [ 0.098 0.087 0.091 0.077 ] 续航 [ 0.164 0.130 0.182 0.154 ]
观察:每一行的 4 个数字都很接近——比如"价格"这一行都在 0.45 ~ 0.52 之间。这说明"从 4 个不同视角看,价格的权重都稳定在 48% 左右",矩阵内部很自洽。如果一行数字忽大忽小(比如 0.1、0.8、0.3、0.6),就说明填矩阵时前后矛盾,后面 CR 大概率不通过。
步骤 2:按行求平均 → 得到权重向量
每一行 4 个数加起来除以 4
价格行 = (0.492 + 0.522 + 0.455 + 0.462) / 4
= 1.931 / 4 = 0.483
性能行 = (0.246 + 0.261 + 0.273 + 0.308) / 4
= 1.088 / 4 = 0.272
外观行 = (0.098 + 0.087 + 0.091 + 0.077) / 4
= 0.353 / 4 = 0.088
续航行 = (0.164 + 0.130 + 0.182 + 0.154) / 4
= 0.630 / 4 = 0.157
拼成权重向量 w
w = [ 0.483, 0.272, 0.088, 0.157 ] 价格 性能 外观 续航 验证: 0.483 + 0.272 + 0.088 + 0.157 = 1.000
注意: 权重向量必然加起来等于 1(因为在算"占比")
步骤 3:算一致性指标 CI(检查矩阵合不合理)
数学结论:
如果判断矩阵"完全没有矛盾",那么 λ_max 恰好等于 n。 (n 是矩阵阶数,本例 n = 4)
所以 λ_max 比 n 多出的那部分,就是'矛盾量'。CI 公式 (λ_max - n) / (n - 1) 就是把这个矛盾量做个标准化。
算 λ_max 的公式
A × w 的第 i 个分量 λ_max = 平均 ───────────────────── w 的第 i 个分量
拆成两小步:
第 1 小步:算 A × w(矩阵乘向量),得到一个 4 维新向量
第 2 小步:让新向量逐元素除以 w,再取平均
第 1 小步:算 A × w
矩阵乘向量的规则——用 A 的每一行 分别 与 w 做'点积'(对应位置相乘再加起来),得到新向量的一个元素。A 有 4 行,新向量就有 4 个元素。
A 的第 1 行是 [1, 2, 5, 3]。跟 w = [0.483, 0.272, 0.088, 0.157] 做点积:
1×0.483 + 2×0.272 + 5×0.088 + 3×0.157 = 0.483 + 0.544 + 0.440 + 0.471 = 1.938
A 的第 2 行是 [1/2, 1, 3, 2]:
0.5×0.483 + 1×0.272 + 3×0.088 + 2×0.157 = 0.242 + 0.272 + 0.264 + 0.314 = 1.092
A 的第 3 行是 [1/5, 1/3, 1, 1/2]:
0.2×0.483 + 0.333×0.272 + 1×0.088 + 0.5×0.157 = 0.097 + 0.091 + 0.088 + 0.079 = 0.354
A 的第 4 行是 [1/3, 1/2, 2, 1]:
0.333×0.483 + 0.5×0.272 + 2×0.088 + 1×0.157 = 0.161 + 0.136 + 0.176 + 0.157 = 0.630
拼起来得到 A × w:
A × w = [ 1.938, 1.092, 0.354, 0.630 ]
3.5 第 2 小步:除以 w 再取平均
把 A×w 的 4 个元素分别除以 w 对应位置的元素:
1.938 / 0.483 = 4.012 1.092 / 0.272 = 4.015 0.354 / 0.088 = 4.023 0.630 / 0.157 = 4.013
通俗理解: 注意这 4 个数都在 4 附近!这就是"矩阵一致性好"的直接表现。如果算出来是 3.5、5.2、4.8、3.9 这种忽高忽低,就是矩阵矛盾大。
取平均得到 λ_max:
λ_max = (4.012 + 4.015 + 4.023 + 4.013) / 4 = 16.063 / 4 ≈ 4.016 (保留位数不同,4.02 ~ 4.05也都对)
代入 CI 公式
CI = (λ_max - n) / (n - 1) 这里 n = 4 (4 个指标),λ_max ≈ 4.05: CI = (4.05 - 4) / (4 - 1) = 0.05 / 3 ≈ 0.017
CI 越接近 0,说明矩阵越自洽。CI = 0 是完美一致。但 CI 单看没用——4×4 和 9×9 的容忍度不一样,所以下一步要用 RI 做标准化。
步骤 4:算一致性比率 CR + 查表判合格
完全随机填矩阵'的平均 CI,就叫 RI(Random Index)
通俗理解: RI 是"完全瞎填也能拿到的基准分"。用算出的 CI 除以 RI,得到 CR——CR 越小,说明和误差相比越远，越准确。
RI 查表
n 3 4 5 6 7 8 9 ───────────────────────────────────────────────────── RI 0.58 0.90 1.12 1.24 1.32 1.41 1.45
本例 n = 4,查表得 RI = 0.90。
代入 CR 公式
CR = CI / RI = 0.017 / 0.90 ≈ 0.019
4.4 与阈值 0.10 比较,判合格
CR < 0.10 → 通过,权重 w 可以放心用 CR ≥ 0.10 → 矩阵前后矛盾太大,回去改数字
本例 CR ≈ 0.019 << 0.10,通过一致性检验
0.10 是 经验阈值——CR = 0.10 意味着你的矩阵比偶然随机填好 10 倍以上,一般认为达到这个标准,判断就足够合理了。数模比赛和学术论文全都用这个标准。
注意: 如果不通过,不要在矩阵里到处乱改。找那个"归一化后行内数字忽大忽小"的指标——最不稳的就是最矛盾的,优先改跟它有关的那几个格子。
把 4 步串起来
原始判断矩阵 A ▼ 步骤 1:按列除以列和 (每列变成占比) 归一化矩阵 ▼ 步骤 2:按行取平均 (4 个视角综合) 权重向量 w = [0.483, 0.272, 0.088, 0.157] ← 最终产品 ▼步骤 3:反向检验 ▼ 算 A × w,除 w,取平均 = λ_max ▼ CI = (λ_max - n) / (n - 1) ▼ CI = 0.017 ▼ 步骤 4:查表 RI,算 CR CR = 0.019 < 0.10 权重可信(若不通过 → 回步骤 0 改矩阵)
自检清单
① 归一化矩阵 每列 加起来必须 = 1(除法算错的信号)
② 权重向量 w 所有元素加起来必须 = 1(平均算错的信号)
③ λ_max 必然 ≥ n(数学定理,如果算出来 < n 肯定错了)
④ CR < 0.10 才算通过;不通过就要修矩阵重新算,不要硬用
