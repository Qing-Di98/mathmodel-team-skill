TOPSIS
一、原始数据表
3 台候选手机 A/B/C,4 个评价指标:价格、性能、外观、续航。
4 个指标的属性:
价格:越小越好(成本型 / 逆向指标)
性能、外观、续航:越大越好(效益型 / 正向指标)
专家给的权重(假设已经用 AHP 算出): w = (0.4, 0.3, 0.1, 0.2)
意思是价格最重要(0.4),性能次之(0.3),续航第三(0.2),外观最轻(0.1)。
二、第 1 步:指标正向化
TOPSIS 后面要'每列取最大值当作正理想解'。如果价格不翻过来,0.5 元(最贵)就会被当成'最好方案',逻辑完全反了。所以必须先把'越小越好'的价格,翻成'越大越好'。"
常用两种方法
方法一(推荐,好懂): x' = max(x) - x 方法二(备用): x' = 1 / x (x 不能为 0) 这里我们用方法一。
手算价格列
价格列的最大值: max = max(0.30, 0.50, 0.40) = 0.50 价格_A' = 0.50 - 0.30 = 0.20 ← 原来最便宜,翻完最大 价格_B' = 0.50 - 0.50 = 0.00 ← 原来最贵,翻完最小 价格_C' = 0.50 - 0.40 = 0.10
正向化后的数据表(4 列全变成"越大越好"):
进入第 2 步之前,每一列必须都是"越大越好"。
三、第 2 步:每列归一化
公式
z_ij = x_ij / √( Σ_i x_ij² ) 每一列自己除以自己那列的"平方和开根"
第 1 列(价格')
分母 = √(0.20² + 0.00² + 0.10²) = √(0.04 + 0 + 0.01) = √0.05 = 0.2236 z_A1 = 0.20 / 0.2236 = 0.894 z_B1 = 0.00 / 0.2236 = 0.000 z_C1 = 0.10 / 0.2236 = 0.447
第 2 列(性能)
分母 = √(85² + 95² + 70²) = √(7225 + 9025 + 4900) = √21150 = 145.43 z_A2 = 85 / 145.43 = 0.584 z_B2 = 95 / 145.43 = 0.653 z_C2 = 70 / 145.43 = 0.481
第 3 列(外观)
分母 = √(80² + 90² + 75²) = √(6400 + 8100 + 5625) = √20125 = 141.86 z_A3 = 80 / 141.86 = 0.564 z_B3 = 90 / 141.86 = 0.634 z_C3 = 75 / 141.86 = 0.529
第 4 列(续航)
分母 = √(24² + 30² + 20²) = √(576 + 900 + 400) = √1876 = 43.31 z_A4 = 24 / 43.31 = 0.554 z_B4 = 30 / 43.31 = 0.693 z_C4 = 20 / 43.31 = 0.462
归一化矩阵 Z(每列的数字现在都在 0~1 之间):
四、第 3 步:乘权重 → 加权归一化矩阵 V
公式
V_ij = w_j × z_ij 权重 w = (0.4, 0.3, 0.1, 0.2)
逐格计算
手机 A: V_A1 = 0.4 × 0.894 = 0.358 V_A2 = 0.3 × 0.584 = 0.175 V_A3 = 0.1 × 0.564 = 0.056 V_A4 = 0.2 × 0.554 = 0.111 手机 B: V_B1 = 0.4 × 0.000 = 0.000 V_B2 = 0.3 × 0.653 = 0.196 V_B3 = 0.1 × 0.634 = 0.063 V_B4 = 0.2 × 0.693 = 0.139 手机 C: V_C1 = 0.4 × 0.447 = 0.179 V_C2 = 0.3 × 0.481 = 0.144 V_C3 = 0.1 × 0.529 = 0.053 V_C4 = 0.2 × 0.462 = 0.092
加权归一化矩阵 V:
五、第 4 步:找正理想解 V⁺ 和负理想解 V⁻
正理想解 V⁺(每列取最大)
价格' 列: max(0.358, 0.000, 0.179) = 0.358 ← 来自 A 性能 列: max(0.175, 0.196, 0.144) = 0.196 ← 来自 B 外观 列: max(0.056, 0.063, 0.053) = 0.063 ← 来自 B 续航 列: max(0.111, 0.139, 0.092) = 0.139 ← 来自 B V⁺ = (0.358, 0.196, 0.063, 0.139) 想象成一台"价格最低+性能最强+外观最好+续航最长"的完美手机
负理想解 V⁻(每列取最小)
价格' 列: min(0.358, 0.000, 0.179) = 0.000 ← 来自 B 性能 列: min(0.175, 0.196, 0.144) = 0.144 ← 来自 C 外观 列: min(0.056, 0.063, 0.053) = 0.053 ← 来自 C 续航 列: min(0.111, 0.139, 0.092) = 0.092 ← 来自 C V⁻ = (0.000, 0.144, 0.053, 0.092) 想象成一台"最贵+最差性能+最丑+最短续航"的垃圾手机
通俗理解: V⁺ 和 V⁻ 都是"虚拟的"——它们不一定对应任何一台真实手机。这两个点只是空间中的两个"锚点",用来做距离比较的参照物。
六、第 5 步:算距离 + 贴近度
公式(欧氏距离)
D⁺_i = √Σ_j (V_ij - V⁺_j)² 到"完美手机"的距离 D⁻_i = √Σ_j (V_ij - V⁻_j)² 到"垃圾手机"的距离 C_i = D⁻_i / (D⁺_i + D⁻_i) 贴近度,越大越好
手机 A 到 V⁺ 的距离 D⁺_A
V_A V⁺ 差 差² 价格 0.358 0.358 0.000 0.000000 性能 0.175 0.196 -0.021 0.000441 外观 0.056 0.063 -0.007 0.000049 续航 0.111 0.139 -0.028 0.000784 总和 = 0.001274 D⁺_A = √0.001274 = 0.0357
手机 A 到 V⁻ 的距离 D⁻_A
V_A V⁻ 差 差² 价格 0.358 0.000 0.358 0.128164 性能 0.175 0.144 0.031 0.000961 外观 0.056 0.053 0.003 0.000009 续航 0.111 0.092 0.019 0.000361 总和 = 0.129495 D⁻_A = √0.129495 = 0.3598
手机 B 的距离(同样算法)
D⁺_B: 只有价格列有差(0.000 - 0.358 = -0.358),其余三列 B 就是 V⁺ = √[(-0.358)² + 0 + 0 + 0] = √0.128164 = 0.3580 D⁻_B: 价格列 B 就是 V⁻(0-0),另外三列有差 = √[0 + (0.196-0.144)² + (0.063-0.053)² + (0.139-0.092)²] = √[0 + 0.002704 + 0.000100 + 0.002209] = √0.005013 = 0.0708
手机 C 的距离
D⁺_C: = √[(0.179-0.358)² + (0.144-0.196)² + (0.053-0.063)² + (0.092-0.139)²] = √[0.032041 + 0.002704 + 0.000100 + 0.002209] = √0.037054 = 0.1925 D⁻_C: 除价格列外其他三列 C 都是最小(等于 V⁻),只有价格列有差 = √[(0.179-0)² + 0 + 0 + 0] = √0.032041 = 0.1790
算贴近度 C_i 并排序
C_A = D⁻_A / (D⁺_A + D⁻_A) = 0.3598 / (0.0357 + 0.3598) = 0.3598 / 0.3955 = 0.910 C_B = D⁻_B / (D⁺_B + D⁻_B) = 0.0708 / (0.3580 + 0.0708) = 0.0708 / 0.4288 = 0.165 C_C = D⁻_C / (D⁺_C + D⁻_C) = 0.1790 / (0.1925 + 0.1790) = 0.1790 / 0.3715 = 0.482
最终结果表:
结论:A > C > B。手机 A 综合最好——D⁺ 只有 0.0357(几乎贴着完美方案),D⁻ 却有 0.3598(离垃圾很远)。手机 B 反过来,虽然性能续航都拉满,但价格权重太高,把它的'最贵'这个大缺陷放大了,拖到第三名。"
Python 代码
import numpy as np # 原始数据(3 方案 × 4 指标) X = np.array([[0.30, 85, 80, 24], [0.50, 95, 90, 30], [0.40, 70, 75, 20]], dtype=float) w = np.array([0.4, 0.3, 0.1, 0.2]) # 第 1 步:价格正向化(第 0 列是成本型) X[:, 0] = X[:, 0].max() - X[:, 0] # 第 2 步:向量归一化 Z = X / np.sqrt((X**2).sum(axis=0)) # 第 3 步:加权 V = Z * w # 第 4 步:正/负理想解 V_pos = V.max(axis=0) V_neg = V.min(axis=0) # 第 5 步:距离 + 贴近度 D_pos = np.sqrt(((V - V_pos)**2).sum(axis=1)) D_neg = np.sqrt(((V - V_neg)**2).sum(axis=1)) C = D_neg / (D_pos + D_neg) for i, c in enumerate(C): print(f"手机 {chr(65+i)}: D+={D_pos[i]:.4f} D-={D_neg[i]:.4f} C={c:.3f}") # 输出: # 手机 A: D+=0.0357 D-=0.3598 C=0.910 # 手机 B: D+=0.3580 D-=0.0708 C=0.165 # 手机 C: D+=0.1925 D-=0.1790 C=0.482
