灰色GM(1,1)完整数学推导
### 一、灰色预测GM(1,1)
到底什么是灰色预测？为什么数模国赛非要用它？
在数学建模里，数据分三类，这是灰色模型的核心逻辑，记住就彻底懂了：
白色系统：信息完全已知 → 公式、规律完全确定（比如纯数学函数）
黑色系统：信息完全未知 → 完全找不到任何规律
灰色系统：信息残缺、数据很少、规律模糊（数模国赛90%预测题都是这类）
GM(1,1)灰色预测，就是专门解决「数据少、看不出规律、样本不够」的预测算法。
1. 为什么普通回归、统计模型不能用，非要用灰色？
有8个月游客数据：[132,145,138,156,160,153,168,172]
肉眼观察：忽高忽低、波动杂乱、没有笔直的线性趋势、样本只有8个（极少）
线性回归：需要大量平稳数据，8个点拟合出来完全不准，直接作废
ARIMA、传统时序：至少需要20+样本，小样本直接失效
插值：只能补中间空缺，不能预测未来
灰色预测的核心
原始小样本数据：杂乱、波动大、随机性强、看不出任何趋势 → 无法建模
灰色模型专属操作：AGO一次累加
累加的作用：把乱七八糟跳动的数据，变成一条平滑、单调上升的曲线！
举个极简实操例子：
原始杂乱序列 X0：[2, 4, 3, 5, 4, 6]
累加后光滑序列 X1：[2, 6, 9, 14, 18, 24]
原本上下跳动的数据，累加后变成了超级规整的上升趋势！
这就是灰色模型能做小样本预测的核心本质：弱化随机噪声、强化整体趋势。
3. GM(1,1)名字通俗解读
第一个1：1个变量（单变量时序，国赛预测题全满足）
第二个1：1阶微分方程（简单线性拟合，计算稳定不炸模）
4. 灰色预测完整通俗流程（替代复杂公式，看懂即会建模）
步骤1：原始杂乱数据 X0：小样本、波动大、无规律（输入数据）
步骤2：AGO累加生成 X1：数据变光滑、趋势显性化（核心操作）
步骤3：紧邻均值平滑：进一步消除残留波动
步骤4：最小二乘求参数a、b：a=发展速度，b=基础增量
步骤5：拟合光滑曲线、预测未来累加值
步骤6：IAGO累减还原：把光滑预测值还原为真实数据量级（输出结果）
5. 两个核心参数通俗解释
发展系数 a：代表数据的变化快慢、收敛速度
a越小 → 趋势越稳 → 预测越准
a＞0.5 → 数据波动太大 → 模型作废，不能用
灰作用量 b：代表系统的基础驱动值、基准增量
6. 国赛绝对核心使用规则
样本 3～15 个、单变量、杂乱波动、短期预测 → 必选 GM(1,1)
样本 ≥20、趋势平稳 → 放弃灰色，用回归/ARIMA
灰色只能 短期3-6期预测，长期不行（国赛扣分重灾区）
7. 总结面对少量、杂乱、无规律的时序数据，普通模型看不懂趋势，灰色模型通过累加变平滑，强行提炼出隐形趋势，实现高精度短期预测。
国赛硬性适用条件
样本数量：单变量时序数据 3≤n≤15（小样本刚需）
数据特征：无正态分布要求、数据波动大、贫信息、数据残缺
预测范围：仅适合短期3-6期预测（国赛默认规则）
对比区别：样本≥20必用回归，样本≤15优先灰色预测

1. 什么是时间序列（Time Series）
时间序列是指：按固定时间间隔、依次采集的有序观测数据序列。核心特征：数据有序、前后存在相关性、随时间动态变化。
数模国赛所有预测题 90% 都是时序题：月度销量、年度产量、每日客流、环境监测数据、疫情数据、能耗数据、经济指标全部属于时序数据。

2. 时间序列四大核心组成成分（国赛论文可直接写）
趋势项 Trend：整体上升/下降/平稳的长期走向（回归模型主要捕捉趋势）
季节项 Seasonal：周期性波动（一年、一月、一周循环）
周期项 Periodic：非固定周期波动
随机项 Noise：随机噪声、误差、扰动（灰色模型核心弱化该项）
时序建模本质：剥离噪声、拟合趋势、推演未来

（1）大样本时序（n ≥ 20）
数据充足、趋势明显、统计规律稳定 适配模型：线性回归、ARIMA、LSTM 不推荐灰色预测（精度低、没必要）

数据稀缺、无统计分布、波动大、样本不足以支撑回归/时间序列统计模型 适配模型：GM(1,1)灰色预测（国赛独家最优解）
4. 时间序列预测两大任务（考试/国赛必考区分）
内插补全：填补序列中间缺失数据 → 只能用插值法（线性/三次样条）
外推预测：预测未来未知数据 → 只能用回归 / GM(1,1) / ARIMA
高频易错国赛扣分点：插值绝对不能外推未来数据！
5. 国赛时间序列模型完整选型口诀（直接背）
缺中间数据、不预测未来 → 插值
数据多、趋势稳、预测长期 → 线性回归
数据极少、短期预测、无分布 → GM(1,1)
数据量大、周期性强 → ARIMA、时序分解
6. 为什么小样本时序必须用灰色GM(1,1)？（国赛论文原理金句）
传统时间序列模型（回归、ARIMA）依赖大量样本统计规律，小样本下统计特征失效、拟合偏差极大；而灰色模型通过一次累加AGO变换，将无序波动的原始时序转化为单调递增的光滑序列，弱化随机噪声，挖掘数据内在隐性规律，在信息贫乏、样本稀缺的时序场景下具备独特优势。

| python # 导入数值计算库，用于数组、矩阵运算、指数、累加等数学操作 import numpy as np # 导入表格处理库，读取csv清洗后的时序数据 import pandas as pd # 导入绘图库，绘制真实值与GM(1,1)预测对比图 import matplotlib.pyplot as plt # 设置绘图全局中文字体，防止图表中文显示方框乱码（Windows系统可用） plt.rcParams["font.family"] = ["SimHei", "Microsoft YaHei"] # 解决坐标轴负号显示异常，避免负号变成方块 plt.rcParams["axes.unicode_minus"] = False # 封装GM(1,1)灰色预测模型类，方便直接调用 class GM11: # 类初始化函数，传入原始时序数据，自动完成AGO、紧邻均值、求解a、b全套计算 def __init__(self, raw_data): # 将输入原始时序转为浮点数组，存入零阶原始序列X0 self.X0 = np.array(raw_data, dtype=np.float64) # 获取原始数据样本总长度 self.n = len(self.X0) # 1. AGO一次累加生成光滑序列X1，抹平原始数据随机波动 self.X1 = np.cumsum(self.X0) # 2. 紧邻均值序列Z1生成，进一步平滑序列 self.Z1 = [] # 从第2个数据到最后一个，循环计算相邻两项均值 for i in range(1, self.n): # 紧邻均值公式：0.5*X1(k)+0.5*X1(k-1) z = 0.5 * (self.X1[i] + self.X1[i-1]) self.Z1.append(z) # 转为n-1行1列二维矩阵，满足矩阵运算格式 self.Z1 = np.array(self.Z1).reshape(-1, 1) # 构造最小二乘求解所需矩阵B：第一列-Z1，第二列全1 self.B = np.hstack([-self.Z1, np.ones_like(self.Z1)]) # 构造常数项矩阵Y，取原始序列第2项到末尾 self.Y = self.X0[1:].reshape(-1, 1) # 最小二乘公式求解[a;b] = (B.T*B)^-1 * B.T * Y self.para = np.linalg.inv(self.B.T @ self.B) @ self.B.T @ self.Y # 提取发展系数a，控制序列增长速度 self.a = self.para[0, 0] # 提取灰作用量b，系统基础驱动量 self.b = self.para[1, 0] # 记录累加序列初始值，用于预测公式计算 self.x1_init = self.X0[0] # 预测函数，step为需要向后外推的期数 def predict(self, step=3): """ step: 向后预测期数（国赛常用3-6期） return: 历史拟合值 + 未来预测值 完整序列 """ # 总长度 = 原始样本数量 + 预测期数 total_len = self.n + step # 存储累加序列的预测值X1_hat X1_hat = [] # 循环代入时间响应函数，计算每一期累加预测值 for k in range(total_len): # GM(1,1)核心时间响应公式 x1_k = (self.x1_init - self.b / self.a) * np.exp(-self.a * k) + self.b / self.a X1_hat.append(x1_k) # 转为数组方便运算 X1_hat = np.array(X1_hat) # IAGO累减还原，把累加序列还原成原始量级数据 X0_hat = [X1_hat[0]] for i in range(1, len(X1_hat)): # 当前累加值 - 前一期累加值 = 当期原始值预测 X0_hat.append(X1_hat[i] - X1_hat[i-1]) # 返回完整拟合+预测序列 return np.array(X0_hat) # ===================== 国赛通用调用模板 ===================== # 程序入口，单独运行该文件时执行下面代码 if __name__ == "__main__": # 读取提前清洗好的csv时序文件（已插值补缺失、IQR修正异常） df = pd.read_csv("clean_time_data.csv") # 提取预测指标列，转为一维数组作为GM(1,1)输入 y_series = df["clean_y"].values # 实例化灰色预测模型，传入原始时序 gm_model = GM11(y_series) # 向后预测4期，得到全部拟合+未来预测结果 pred_all = gm_model.predict(step=4) # 打印分隔标题，输出模型核心参数 print("========== GM(1,1)模型核心参数 ==========") # 保留4位小数输出发展系数a print(f"发展系数 a = {gm_model.a:.4f}") # 保留4位小数输出灰作用量b print(f"灰作用量 b = {gm_model.b:.4f}") print("\n拟合+未来预测完整序列：") # 所有数值保留2位小数打印，格式整洁 print(np.round(pred_all, 2)) # 创建绘图画布，设定宽10高6英寸，适配论文图表 plt.figure(figsize=(10, 6)) # 绘制真实数据散点，红色，点大小50，设置图例名称 plt.scatter(range(1, len(y_series)+1), y_series, c="#e74c3c", s=50, label="真实观测数据") # 绘制模型拟合+预测整条蓝色曲线，线条粗细2.5 plt.plot(range(1, len(pred_all)+1), pred_all, c="#2980b9", linewidth=2.5, label="GM(1,1)模型预测序列") # X轴标签 plt.xlabel("时序编号", fontsize=12) # Y轴标签 plt.ylabel("指标数值", fontsize=12) # 图表标题，可直接截图放进竞赛论文 plt.title("基于GM(1,1)灰色预测模型的时序数据分析与预测", fontsize=13) # 显示图例区分散点和曲线 plt.legend(fontsize=11) # 添加浅灰色网格，方便读数，透明度0.3不遮挡线条 plt.grid(alpha=0.3) # 自动调整布局，防止标题、标签被截断 plt.tight_layout() # 弹出窗口展示绘图结果 plt.show() |
