二、数据处理是预测前置步骤
2.1 标准流水线
原始采集数据 → 数据探查 → 去重 → 缺失值修复 → 异常值修正 → 插值补全 → 标准化（回归专用） → 预测建模 → 模型精度评估 → 预测结果输出
2.2 脏数据对预测模型的负面影响
缺失值 小样本时序（灰色预测）删除缺失样本会直接导致模型失效；序列趋势断裂，回归斜率偏移、灰色累加序列失真，预测误差翻倍。
异常值（离群点） 线性回归最小二乘算法对极端值高度敏感，单个异常值会完全改变回归直线；GM (1,1) 累加序列被异常值干扰，发展系数 a 严重失真。
重复冗余数据 无新增有效信息，增加计算量，不会提升模型精度，极易引发过拟合。
格式错误数据 数字混杂文字、单位不统一、日期格式混乱，代码直接报错，无法数值建模。

三、数据分类与脏数据分类
3.1 两类建模核心数据
单变量时序数据（插值、灰色预测专用） 仅包含时间 t 与对应指标 y，无其他影响因素，例：月度销量、每日客流量、年度产量。 示例： t：1,2,3,4,5 y：22,25,NaN,30,33
多变量面板数据（多元回归专用） 多个自变量 X₁,X₂… 搭配单个因变量 Y，变量间存在因果逻辑。 示例： X₁(温度):25,28,30 X₂(广告投入):1000,1500,1200 Y (销量):320,410,360
3.2 四类脏数据详解
缺失值 表现：空白单元格、NaN、Null、占位符 “-”“0”； 分类：随机缺失、连续成片缺失； 处理原则：时序数据优先插值填充；大样本少量缺失可删除。
异常值（离群点） 分类：设备故障错误值、真实偶然极值； 处理原则：故障值替换修正；真实极值保留（不超过一个数量级的极值），分段建模。
重复数据 完全重复行、关键指标重复次要字段不同； 处理原则：完全重复直接删除；关键字重复做标记留存。
格式错误数据 数字混汉字、单位混用、日期格式不统一； 处理原则：统一格式，清洗字符转换为纯数值。

三、步骤 2：缺失值三类处理方案对比
方案 1：删除法 dropna ()
适用场景：数据总量大，缺失样本占比＜5%，缺失随机分布 禁用场景：灰色预测、小样本时序数据（删除会减少序列长度，模型失效）

方案 2：统计量填充（均值 / 中位数 / 众数）
均值填充：无异常值、数据近似正态分布
中位数填充：存在异常值，稳健性更强（建模考试首选统计填充方式）
方案 3：插值填充（时序预测最优方案，衔接插值拟合章节）

四、步骤 3：异常值检测与修正
两种工业界、考试通用方法：3σ 准则、IQR 四分位箱线法
方法 1：3σ 准则（正态分布数据专用）
判定规则：数值 > 均值 + 3σ 或 数值 < 均值 3σ → 异常值
方法 2：IQR 四分位法（通用，不要求正态）
判定规则： Q1：下四分位数（25% 分位点） Q3：上四分位数（75% 分位点） 四分位距 IQR = Q3 Q1 上边界 = Q3 + 1.5IQR 下边界 = Q1 1.5IQR 超出上下边界全部判定为异常值

一元与多元线性回归模型、最小二乘推导、评价指标
一、线性回归模型原理与适用场景
回归核心：挖掘自变量 X 与因变量 Y 的线性因果关系，可向区间外长期外推预测。插值只能补全中间数据，回归可以预测未来数据，是建模考试最大区别点。
一元线性回归：单个自变量（时间 t→产量 y） 模型公式：\hat y = a + bx a：截距，b：回归系数（斜率）
多元线性回归：多个自变量X_1,X_2...X_n 模型公式：\hat y = a + b_1 X_1 + b_2 X_2 + ... + b_n X_n
二、最小二乘法核心思想
建模核心准则：让所有样本真实值与预测值误差平方和最小。
损失函数： Loss = \sum_{i=1}^n (y_i \hat y\i)^2 = \sum\{i=1}^n (y_i a bx_i)^2
通过对 a、b 求偏导、令导数为 0，解出最优参数，保证拟合直线最贴合数据趋势。
三、模型三大评价指标
决定系数 R²：取值 [0,1]，越接近 1 拟合效果越好，是建模首选评价标准。
均方误差 MSE：误差平方平均值，数值越小模型误差越小。
平均绝对误差 MAE：误差绝对值平均值，不受极端异常值干扰，结果更稳健。

解释：什么是两期外推预测
1、“期”不是固定指“天”，是时间单位，完全看数据的采样间隔
本题数据是按月采集（1月、2月…10月），1期 = 1个月
所以未来两期 = 未来2个月（11月、12月），对应代码里 predict([[11]])、predict([[12]])
如果你的数据是每天记录：1期=1天，两期就是未来2天
如果是季度数据：1期=1个季度，两期就是往后预测2个季度
如果是年度数据：1期=1年，两期就是往后2年
2、什么叫“外推”，和插值区分开
插值（内插）：填补现有数据中间缺失的空白，比如3月数据丢了，用2、4月补上，没有超出已有时间范围；
外推：往现有数据最后一段的后面，预测还没发生的新时间点，超出原有序列范围。
3、拓展（数模国赛通用说法）
3期预测：往后预测3个时间单位
6期短期预测（灰色GM(1,1)常用表述）6-8，12，32，96
长期多期外推：往后预测十几个时间单位（灰色模型不适合长期外推）
