CUMCM 国赛案例讲义
优化模型 + 评价模型历年真题速览
一、国赛里这两种模型出现的频率
优化模型和评价模型是 CUMCM 出现最频繁的两大类。基本上每年 A/B/C/D/E 五道题里,至少有 1 道纯优化,1 道纯评价,还有 1~2 道'优化+评价混合'的
按题型统计的经验规律(近 10 年):
C 题:70% 的年份含优化模型(资源分配、生产调度、路径规划、种植策略)
B 题:50% 的年份含评价+优化混合(赛事安排、方案比选)
D 题:60% 的年份纯评价模型(方案打分、供应商评估)
A 题:偏物理/工程,较少用这两个模型,但会用作辅助
E 题:近年新增,数据分析为主,评价常出现
二、优化模型历年真题速览
★★★ 2024 C 题:农作物的种植策略(最经典)
题目背景:
华北山区的乡村,有 34 块耕地共 1201 亩,分为平旱地、梯田、山坡地、水浇地 4 种,还有 16 个大棚(普通+智慧)。要在 2024–2030 年 7 年间,为 41 种农作物排产,让 7 年总利润最大。
为什么是纯优化题:
决策目标明确 —— 让利润最大
决策变量清晰 —— 每块地、每年、每季、种什么、种多少
有一堆约束 —— 地块面积、豆类三年一轮、不能重茬、大棚只能种蔬菜/食用菌等
★★ 2001 B 题:公交车调度
题目:某公交线路一天中不同时段客流不同,要设计发车间隔,让乘客等车时间最短的同时,车辆运营成本最低。
模型:
决策: n_t = 第 t 时段发车数量 ← 整数 目标: min (乘客总等车时间 + λ × 运营总成本) ← 多目标加权 约束: 发车间隔 ∈ [3, 10] 分钟 任意时刻满载率 ≤ 120%
为什么经典:第一次把"两个矛盾目标"合成一个式子,教会大家用"加权法/ε-约束法"处理多目标。
★★ 2002 D 题:赛程安排
题目:n 个队打循环赛,要排一张时间表,让每支队相邻两场之间间隔尽量均匀。
模型:典型 0-1 指派问题
决策: x_ijt = 队 i 和队 j 在第 t 轮是否比赛 ← 0/1 min max_i (相邻两场间隔的最大值) ← 极小化最大值 约束: Σ_j x_ijt = 1 每支队每轮打且仅打一场 x_ijt = x_jit 比赛对称
★★ 2016 D 题:风电场运行状况分析与优化
题目:根据历史发电数据,给风机分组、调度,让发电量最大、弃风最少。
优化+评价混合 —— 先用 AHP 给风机健康度打分,再用整数规划调度。
★ 2003 A 题:SARS 传播与控制
虽然主体是微分方程,但决策"隔离资源如何分配到各城市"用了线性规划。
三、评价模型历年真题速览
★★★ 2012 A 题:葡萄酒的评价(最经典)
题目背景:
两组评酒员对 27 种葡萄酒打分,存在明显个体差异;同时给出葡萄的 30+ 项理化指标(糖度、总酸、花色苷等)。要求:(1) 判断两组评分是否可信;(2) 根据理化指标给酒分级;(3) 建立葡萄理化指标与葡萄酒质量之间的关系。
为什么是评价题:
有一堆"待评价对象"(27 种酒) + 一堆"评价指标"(30+ 项理化)
没有唯一最优,只有"综合表现最好"的排序
需要给每个指标一个权重(AHP 或熵权法)
解题模板:
第 1 步 · 数据清洗:剔除异常评酒员(用信度检验、组内相关系数 ICC) 第 2 步 · 指标归一化:糖度、酸度等量纲不同,统一到 [0, 1] 第 3 步 · 确定权重: - AHP:专家给指标两两打分算权重 w - 熵权法:数据自身信息熵越大权重越小 - 组合权重:0.6×AHP + 0.4×熵权(常见做法) 第 4 步 · TOPSIS 打分:算每种酒到"最好酒"和"最差酒"的距离,得综合得分 第 5 步 · 分级:按综合得分聚类(K-Means)或分位数分为 3-5 级 第 6 步 · 建立映射:用多元回归/偏最小二乘 PLS 建理化→质量关系
★★ 2010 D 题:对学生宿舍设计方案的评价
题目:给 4 个宿舍设计方案(A/B/C/D)在 8 个指标(采光、通风、面积、造价、安全性、便利性、维护成本、美观度)上评分,选最优方案。
第 1 步 · 建层次结构图:目标层-准则层(8 指标)-方案层(4 方案) 第 2 步 · 专家两两打分构造判断矩阵(8×8) 第 3 步 · 算权重 + CR 一致性检验(参见 09 讲义手算流程) 第 4 步 · TOPSIS 排序,得到 4 个方案的最终得分
★★ 2016 D 题:供应商的选择(评价+优化)
题目:400 多家供应商 5 年的供货数据,先给供应商综合排名,再决定订多少货给谁,让企业成本最小、供货稳定。
解法:
前半段评价:熵权+TOPSIS 给 400 家供应商综合打分,选前 50
后半段优化:对这 50 家做整数规划,决定订货量 x_i
★ 2013 B 题:碎纸片的拼接
虽然是图像匹配题,但"每种匹配方案的可信度"用了 TOPSIS 排序。
★ 2020 C 题:中小微企业信贷决策
给企业信用评级 —— 典型评价 + 后续贷款额度分配 —— 优化。这题是"评价+优化"混合的近年代表。
四、"优化+评价"混合
很多同学有个误区,以为一道题只能用一种模型。其实国赛特别喜欢'先评价再优化'：先用 AHP/TOPSIS 排出'谁重要',再用 LP/IP 决定'重要的那几个分多少资源'。"
常见混合套路:
模式 A · 先评后优: 评价筛选(TOPSIS) → 得到 Top-K 候选 → 优化分配资源(LP/IP) 代表题:2016 D 供应商选择、2020 C 信贷决策、2022 C 玻璃文物成分分析 模式 B · 先优后评: 优化生成多个方案(LP + 敏感性分析) → 评价打分选最终方案(AHP) 代表题:2016 D 风电场调度、2018 A 高温作业专用服装 模式 C · 优化里嵌套评价: 目标函数里的系数是评价打出来的 代表题:2019 C 机场的出租车问题(评价客源等级 → 优化调度)
五、拿到题目后的通用建模五步法
第 1 步:辨题型
看到题目里出现这些关键词 → 优化题: "最大/最小/最优", "如何安排/分配/调度", "使成本最低/利润最高" 看到题目里出现这些关键词 → 评价题: "哪个最好", "对...进行评价/排序/分级", "哪个方案更合理" 两个关键词都出现 → 混合题: "先评价...再决定...", "综合考虑...做出决策"
第 2 步:定变量
优化题:找"你能拿主意的东西",就是决策变量。连续用 x(数量、面积、金额),离散用 y(是否、选不选,0/1)。
评价题:找"待评价对象"和"评价指标"。对象成行,指标成列,组成决策矩阵。
第 3 步:写目标
优化题:所有指标乘以系数加起来,前面 max 或 min。多目标就加权:min (w1·f1 + w2·f2 + ...)。
评价题:目标就是"综合得分",得分 = Σ(权重 × 归一化后的指标值)。
第 4 步:列约束
把题目每句话过一遍,凡是"必须/不能/最多/至少/等于"的都翻译成不等式。常见约束类型:
资源约束: Σ 使用量 ≤ 总量
需求约束: Σ 供应 ≥ 需求
逻辑约束: 是非题用 y ∈ {0,1},连锁关系用 y1 ≥ y2 等
耦合约束: x ≤ M × y (big-M)
互斥约束: y1 + y2 + y3 ≤ 1(三选一或都不选)
第 5 步:求解 + 分析
优化题:PuLP 5 步写完,跑出结果。然后做敏感性分析(改一改系数,看结果怎么变)。
评价题:算完综合得分,一定要做"权重敏感性"——权重变 ±10%,排名会不会颠倒?稳定的模型才是好模型。
六、优化题解题模板
【标准四段式】 1. 问题分析 - 一句话概括:本题决策的是 XXX,目标是 YYY,主要限制是 ZZZ - 分析类型:LP / IP / MILP / 0-1 / 多目标 2. 模型建立 2.1 符号说明表(每个变量、参数都要有中文名+单位+取值范围) 2.2 目标函数(公式 + 文字说明为什么这么写) 2.3 约束条件(编号 ①②③... + 每条中文注释) 2.4 变量取值范围 3. 模型求解 - 用 PuLP / Gurobi 求解,给完整代码 - 结果表格 + 关键图(种植面积热力图、决策变量条形图) 4. 结果分析与检验 - 敏感性分析:关键参数 ±10% 结果变化 - 与实际经验对比(是否符合直觉) - 模型的优缺点
国赛评委最看重"符号说明表"和"敏感性分析"这两块
七、评价题解题模板
【标准五段式】 1. 指标体系构建 - 画层次结构图(目标层-准则层-指标层-方案层) - 说明每个指标的含义、量纲、正/逆向属性 2. 数据预处理 - 缺失值填补(均值/中位数/KNN) - 异常值处理(箱线图剔除) - 正向化(逆向/中间/区间型指标统一变成"越大越好") - 归一化(Min-Max 或 Z-score,量纲统一) 3. 权重确定(建议双权重对比) - 主观权重:AHP(专家打分) - 客观权重:熵权法(数据自身信息量) - 组合权重:w = α·w_AHP + (1-α)·w_熵,α 一般取 0.5~0.7 - CR 一致性检验(见 09 讲义) 4. 综合评价 - TOPSIS:算到理想解距离,得贴近度 C - 也可用:灰色关联、模糊综合评价、Rank-Sum 秩和比 5. 结果分析 - 排序结果表 - 敏感性:权重变 ±10% 排名是否稳定 - 与传统方法(简单平均)对比,说明本模型的优越性
注意: 评价题最容易丢分的三个地方:(1) 忘了正向化,把"成本越低越好"的指标当"越大越好"处理;(2) 只报一种权重方法,没有对比;(3) 排完序就结束,没做敏感性分析,评委会认为你的结果不可信。
八、可直接改的代码骨架
优化题:整数规划 + big-M(以种植题为例)
from pulp import * # 1. 定义问题 prob = LpProblem("Planting", LpMaximize) # 2. 决策变量 I = range(34) # 34 块地 J = range(41) # 41 种作物 T = range(7) # 7 年 x = LpVariable.dicts("x", (I, J, T), lowBound=0) y = LpVariable.dicts("y", (I, J, T), cat="Binary") # 3. 目标 prob += lpSum((price[j] * yield_[j] - cost[j]) * x[i][j][t] for i in I for j in J for t in T) # 4. 约束 for i in I: for t in T: prob += lpSum(x[i][j][t] for j in J) <= area[i] # 面积约束 for j in J: prob += x[i][j][t] <= area[i] * y[i][j][t] # big-M if t > 0: for j in J: prob += y[i][j][t-1] + y[i][j][t] <= 1 # 不重茬 # 5. 求解 prob.solve() print("最大利润:", value(prob.objective))
评价题:AHP+TOPSIS 通用骨架
import numpy as np # ===== AHP:算指标权重 ===== A = np.array([[1, 3, 5], [1/3, 1, 3], [1/5, 1/3, 1]]) # 判断矩阵 A_norm = A / A.sum(axis=0) # 按列归一化 w = A_norm.mean(axis=1) # 按行平均得权重 lam_max = (A @ w / w).mean() CI = (lam_max - len(A)) / (len(A) - 1) RI = {3: 0.58, 4: 0.90, 5: 1.12, 6: 1.24, 7: 1.32}[len(A)] CR = CI / RI assert CR < 0.1, "一致性不通过" # ===== TOPSIS:综合打分 ===== X = np.loadtxt("data.csv", delimiter=",") # 原始数据 n×m X_norm = X / np.sqrt((X**2).sum(axis=0)) # 向量归一化 V = X_norm * w # 加权 V_pos = V.max(axis=0) # 正理想解 V_neg = V.min(axis=0) # 负理想解 D_pos = np.sqrt(((V - V_pos)**2).sum(axis=1)) D_neg = np.sqrt(((V - V_neg)**2).sum(axis=1)) C = D_neg / (D_pos + D_neg) # 贴近度,越大越好 rank = np.argsort(-C) + 1 # 排名(1 是最好)
