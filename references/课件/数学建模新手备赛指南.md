数学建模竞赛新手备赛指南
# 一、了解数学建模竞赛
## 1.1 什么是数学建模
数学建模是将现实世界中的问题抽象为数学语言（方程、不等式、图、矩阵等），通过求解数学模型得到结论，再把结论翻译回现实场景的全过程。竞赛要求你在限定时间内完成「选题 → 建模 → 编程求解 → 撰写论文」的完整链路。
## 1.2 主流赛事一览
建议路线：校赛练手 → 国赛冲奖 → 美赛拓展
## 1.3 比赛流程
开赛后下载题目，从若干道题中选择一道
团队分工：建模手、编程手、写作手（可交叉）
建立数学模型并编程求解
撰写完整论文（含摘要、模型假设、建立与求解、结果分析、灵敏度分析等）
在截止时间前提交论文 PDF/Word
## 1.4 论文结构模板
摘要（最重要，评委第一眼看的内容，300 字内精炼概括问题、方法、结论）
问题重述与分析
模型假设与符号说明
模型建立与求解
结果分析与验证（含灵敏度/误差分析）
模型评价与改进方向
参考文献
附录（代码等）
# 二、你需要储备的知识
## 2.1 数学基础（你已有的）
微积分：求导、积分、微分方程基础
线性代数：矩阵运算、特征值、线性方程组

第一梯队（必学，覆盖 80% 赛题）：

线性规划 / 整数规划（优化问题核心）
TOPSIS 综合评价法
灰色预测模型 GM(1,1)
第二梯队（进阶，锦上添花）：
蒙特卡洛模拟
时间序列分析（ARIMA）
微分方程建模（SIR 传染病模型等）
图论与网络分析
聚类分析（K-means）
主成分分析 PCA

# 三、备赛时间线（以校赛为例，赛前 4-6 周）
## 第 1-2 周：打基础
学习 1-2 个核心模型（推荐：线性规划 + 层次分析法）
入门 Python / MATLAB，能跑通一个完整的建模案例
阅读 1-2 篇优秀获奖论文，了解论文结构和写作风格
## 第 3-4 周：实战模拟
找一道历年真题，限时完成（可适当放宽到 4-5 天）
练习团队分工协作，磨合沟通节奏
再补充 2-3 个模型方法
## 第 5-6 周：冲刺
再做 1 次全真模拟（严格按比赛时长）
准备好论文模板（LaTeX / Word）
整理常用代码片段库（回归、画图、数据清洗等）
确认团队角色分工和时间管理方案

### 审题阶段
"我正在参加数学建模竞赛，题目是 [粘贴题目]。请帮我：1) 拆解这道题的核心问题和子问题；2) 列出每个子问题可能用到的数学模型；3) 建议数据来源和求解思路。"

"请用 Python 实现 [具体模型名称]，数据格式为 [描述数据结构]，需要输出 [期望结果]。请添加详细注释。"
### 论文阶段
"以下是我的模型描述 [粘贴内容]，请帮我润色为学术论文风格，保持逻辑严谨，语言简洁。"

切勿让 AI 完全代替思考——评委能看出来
AI 生成的代码必须运行验证，AI 生成的数据/文献必须核实
摘要和核心创新点必须自己写，这是论文的灵魂

# 五、校赛实战技巧
## 5.1 选题策略
拿到题目后，先花 30-60 分钟快速浏览所有题目
优先选自己有数据获取能力、且团队有相关知识储备的题目
数据分析类 / 评价类题目对新手更友好（模型套路成熟）
避免选需要深厚专业背景（如流体力学）的题目
## 5.2 时间管理（72 小时制）
## 5.3 团队协作要点
明确分工：建模手（负责模型推导）、编程手（负责代码实现与可视化）、写作手（负责论文撰写与排版）
保持实时沟通：建议用共享文档（飞书/腾讯文档/Overleaf）同步编辑

图表要专业：有标题、坐标轴标签、图例、数据来源标注
模型要对比：展示为什么选这个模型（与备选模型对比）
灵敏度分析不能少：改变参数看结论是否稳定
模型评价要诚实：主动指出局限性并提出改进方向，比假装完美更加分

# 七、新手常见误区与避坑指南
误区：模型越复杂越好 → 真相：模型要合理而非复杂。评委看重的是模型与问题的匹配度和逻辑自洽性，用简单模型解决问题反而加分。
误区：代码写得越多越厉害 → 真相：代码是工具不是目的。清晰的图表和正确的结果比代码量重要得多。
误区：摘要随便写写 → 真相：摘要占评审印象的 50% 以上，应最后写、反复改（好的摘要平均修改 10+ 次）。
误区：一开始就动手写代码 → 真相：先花足够时间理解问题和设计模型框架，磨刀不误砍柴工。
误区：三个人各干各的 → 真相：频繁沟通是关键，每个人都要理解整体思路，否则论文会割裂。
误区：完全依赖 AI → 真相：AI 是加速器不是替代品，核心思路和创新点必须自己产出。
