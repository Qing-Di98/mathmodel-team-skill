# 共享契约（双解题手模式专用）

两解题手并行工作的唯一事实源。**阶段 0 共同冻结，冻结后默认只读**；确需修改必须双方在场并记录变更，且相关质检 `PASS` 立即失效复验。

## 文件清单

| 文件 | 内容 | 何时冻结 |
|---|---|---|
| `题目分析报告.md` | 题面理解、子问题边界、每题目标/变量/约束/求解方向、解题手分配 | 阶段 0，M1 之前 |
| `术语表格.md` | 全题统一术语（中文名/英文名/定义/出处），防两人叫法不一 | 阶段 0 |
| `假设清单.md` | 全部假设逐条编号，标注依据与敏感性预检结论 | 阶段 0，M1 审查 |
| `符号表.md` | 全题统一符号（符号/含义/单位/首次出现章节），防合稿冲突 | 阶段 0 |
| `数据口径.md` | 数据来源、清洗口径、单位、缺失处理、公共参数取值 | 阶段 0 |
| `结果锚点表.md` | 阶段 2 对账时生成：两工作区关键数值交叉核对 | 阶段 2 |

## 使用方式

1. 阶段 0 由两人共同填充前 5 个文件（可一人起草、另一人审校）。
2. 阶段 1 双方各自**只读**这些文件，按分配的子问题工作。
3. 阶段 2 用 `结果锚点表.md` 对账：从两份复现清单/RESULTS_REPORT 提取共享参数与关键结论数值，逐一核对。
4. 模板按需增删行；删除条目须记录理由。
