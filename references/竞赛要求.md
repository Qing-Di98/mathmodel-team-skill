# 竞赛要求（全国大学生数学建模竞赛通用）

本队实践整理的要求，建模与写作全流程须遵守；与当届官方规则冲突时，以当届官方规则为准。

## 弹性需求（建模原则）

1. 假设宁精勿多，每问可以有每问的假设。
2. 较为简单的前两问可以用不同模型同时求解（一般两个模型）。结果一致则表述为交叉验证，结果有偏差则需自圆其说，说明不同模型及其结果的适用范围。
3. 题目中有"综合考虑"类似表述时，考虑加入评价模型，若无相关表述也可考虑评价模型，可丰富建模，提高论文的实用性。
4. 一旦出现数据处理，要在论文中**单开章节**进行呈现。

## 硬性要求（格式与作品构成）

当届官方全文见 `论文格式规范2026.md`（全国大学生数学建模竞赛组委会 2026 年修订稿，自发布之日起试行，与本规范不相符处以本规范为准）。以下为提炼要点：

### 纸质版

1. 白色 A4 纸，上下左右页边距各至少 2.5 厘米，左侧装订；第一页承诺书、第二页编号专用页、第三页摘要专用页（摘要含标题和关键词，不超一页，从本页起用阿拉伯数字从 1 连续编号，页脚中部）、第四页起正文（无目录，不超 30 页），正文之后为附录（页数不限，须打印并与正文装订一起提交）。
2. 附录内容：支撑材料的文件列表、建模所用到的全部完整可运行的源程序代码（含 EXCEL、SPSS 等交互命令）；缺少必要源程序、程序不能运行或运行结果与论文不符，可能被取消评奖资格；确实没用程序须明确注明"本论文没有用到程序"。
3. 摘要专用页、正文和附录中任何地方都不能有显示参赛者身份和所在学校及赛区的信息。
4. 所有引用他人或公开资料（包括网上资料）的成果必须按科技论文规范列参考文献并在正文标注。
5. 未作规定的（字号、字体、行距、颜色等）不做统一要求。

### 内容与结构

1. 论文正文的第四部分四五条假设就行，**以五条为最佳，不能超过六条**（弹性需求允许每问有每问的假设）。
2. **假设模块不涉及具体数值、参数类内容**：不得将参数设置纳入假设模块，仅保留宏观通用假设；参数取值放正文首次使用处（或数据说明/4.x 实例化处），并在符号表中登记；假设中**不得出现任何与后面代码/求解相关的实验过内容**（验证、仿真、实测结果一律留在正文）。
3. **假设格式**：`**假设一**：假设……`——中文序号加粗，逐条直接陈述（参照国一 24B 写法）。
4. **符号说明汇总成一张表**：三列（符号、说明、单位），每项居中，无单位用 `-`，以半页纸为宜、不超过一页（参照 24C/25B 三线表写法，25B 表标题"表 1 符号说明"在表格上方）。
5. 建模完一定要做**灵敏度分析**（参数扰动/场景变化对结论方向的影响）。

### 排版硬性细节（本队要求，写作时逐条对照）

1. 多个公式在一起时用**大括号括起来**，不要铺满一行，**大括号（公式组）不标号**；单行独立公式可标号。
2. **符号下标要科学**：论文（PDF）中不能出现类似 `r_A` 这样的带下划线写法，下标必须用真正的下标排版（`r_A`），正文引用处同样适用。
3. **表格标题在表格上方，流程图和数据可视化图的标题在图下方**；表格/图标题的**字号均不能大于或等于正文字体**（须小于正文），且**一律采用黑色**。
4. **表述清洁（书面化）**：正文、摘要、图表标题一律书面语——不得出现 `→`、`✓` 等非书面符号；单位用法全篇统一，`/` 与 `、` 不得混用；表述要有完整的逻辑，杜绝机械化模板腔（2019 C 题教训：全篇表述太机械、摘要不书面、`→` 与 `✓` 遍地均被要求整改）。
5. **修订纪律（数值锚点不可变）**：论文进入修订轮次后，**已验证数值一律不动**（如 $\lambda_{\max}$、$c^*$、$\alpha^*$ 及各结果表数字）——修订只允许改表述、结构、图表形式；确需改动数值，必须重跑对应代码验证并同步更新结果表与图表，禁止只改论文中的数字。

### 电子版（务必严格遵守）

1. 按《报名和参赛须知》要求提交**参赛论文**和**支撑材料**两个电子文件。
2. 参赛论文电子版内容必须与纸质版内容及格式（包括附录）**完全一致**；必须是**一个单独的文件**，格式为 **PDF 或 Word 之一（建议 PDF）**；**文件大小不超过 20MB**；**不要压缩**。
3. **承诺书和编号专用页不要放在电子版论文中，电子版论文的第一页必须为摘要专用页。**
4. 支撑材料：用于支撑模型、结果、结论的所有必要材料，至少包含所有可运行源程序、自主查阅使用的数据资料（赛题提供的原始数据除外）、较大篇幅中间结果的图表等；使用 **WinRAR 压缩在一个文件（RAR 或 ZIP，大小不超过 20MB）**；支撑材料文件列表应放入论文附录；确实没有支撑材料须在附录注明"本论文没有支撑材料"；支撑材料与论文内容不符可能被取消评奖资格。
5. 承诺书和编号专用页不要放在支撑材料中；所有文件中不能有显示参赛者身份和所在学校及赛区的信息。
