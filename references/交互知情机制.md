# 交互知情机制（用户全程参与，禁止黑箱推进）

> 用户明确要求（2026-08-14）：**建模和代码的每一个关键 Step 都要让用户参与并知情**，每一步都留给用户思考空间。禁止把建模/代码阶段当黑箱一口气跑完再汇报。本机制是全局规则，主 SKILL.md 与 2analysis-modeling / 3coding-visual 每个 Step 均须执行。

## 一、两级交互（知情 + 决策）

不是每步都阻塞等待确认（会拖死流程），而是**两级交互**：

### 1. 知情层（inform）——每个关键 Step 结束必做

每完成一个关键 Step，向用户**简洁汇报**，格式固定：

```
【Step N 结果】<这一步做了什么、得到什么关键结论/数值>
【含义】<这个结果说明什么，对后续的影响>
【下一步】<打算做什么，为什么>
```

- 汇报控制在 3-5 句，禁止长篇倾倒过程。
- 汇报后**留给用户思考空间**：用户可能提出异议、补充信息、调整方向；不得说完立刻自己往下冲（同一轮工具调用里说完就继续跑下一步，等于没有留空间）。
- 用户没有异议时，按汇报中的"下一步"继续。

### 2. 决策层（confirm）——关键决策点必做

遇以下节点，必须用 `决策确认机制.md` 的选项（1.是 / 2.否 / 3.其他）等用户明确选择后才能执行：

- 模型选取 / 模型切换（如 ARIMA vs SARIMA vs GM(1,1)）。
- 假设的提出与取舍。
- 数据口径（缺失处理方案、异常值策略、区间划分）。
- 参数取值与参数确定方式（如 p、q、d 的确定方法）。
- 结果不理想时的处理方向（换模型 / 调参 / 简化问题）。

## 二、课件流程的"每步留思考空间"示范（ARIMA/SARIMA 七步）

以 `课件/数据处理与预测模型/2ARIMA&SARIMA时间序列模型零基础全解.md` 的国赛七步为例，**每步执行完按知情层汇报，并在指定处给用户思考空间**：

| 步骤 | 执行内容 | 完成后向用户汇报/留思考空间 |
|---|---|---|
| 1. 时序可视化与特征分析 | 画时序折线图，判趋势/波动/周期 | 汇报：图中看到什么（趋势/周期/突变）；**留思考**：是否同意"无固定周期→ARIMA / 有固定周期→SARIMA"的初步判断？ |
| 2. 平稳性检验（ADF 必做） | 跑 ADF，得 P 值 | 汇报：P=xx，序列平稳/非平稳；**留思考**：是否需要差分（d=0/1/2），是否符合直觉 |
| 3. 确定最优差分阶数 d | 差分后重检验 | 汇报：差分 n 次后平稳；**留思考**：展示差分前后对比图，问是否接受该 d |
| 4. 确定最优 p、q | ACF/PACF 判参 + AIC/BIC 遍历 | 汇报：ACF/PACF 显示截尾/拖尾情况 → p=?, q=?；AIC/BIC 遍历最优组合；**留思考**：是否接受参数，还是换遍历范围/用万能组合 |
| 5. 构建并训练模型 | 拟合训练 | 汇报：模型收敛、主要参数估计值；**留思考**：是否继续下一步残差检验 |
| 6. 残差白噪声检验（必写结题依据） | 残差检验，得 P 值 | 汇报：残差 P=xx，白噪声/非白噪声；**留思考**：若非白噪声，是调参还是换模型（决策层确认） |
| 7. 拟合 + 未来预测 + 结果分析 | 外推预测、精度指标 | 汇报：R²/MSE/MAE、预测值；**留思考**：预测结果是否合理，是否调整预测期数；最后汇总征询 |

> 示范要点：**每步都先给"结果 + 含义 + 下一步"**，在决定模型走向的节点（步骤 1 选型、步骤 4 定参、步骤 6 残差不合格、步骤 7 结果不合理）升级为决策层确认。其他课件流程（数据预处理四模型选型、优化模型三要素、评价模型）同理：**每个关键步骤结束即汇报、给思考空间**。

## 三、3coding-visual 的交互要求

- **Step 2 逐子问题实现**：每完成一个子问题（含代码、运行、结果表、求解报告），即按知情层汇报该子问题的关键数值与校验情况；**禁止连续实现多个子问题后一次性汇报**。
- **运行失败/结果异常**：先汇报现象与可能原因（1-2 句），给用户思考空间（是否接受当前口径/换实现/简化），再继续。
- **出图**：完成图表时汇报图表类型与数据来源；需要用户挑选展示方式时用决策层确认。

## 四、话术与纪律

- 汇报即"知情"，决策确认即"参与"；两者缺一不可。
- 用户打断、提问、纠正时，停下当前推进，先回应。
- 双解题手模式：两解题手的进展按子问题分开展示，各自的关键 Step 同样走两级交互（主 Agent 汇总后向用户汇报）。
- 不要把"已在报告里写了"当作"已让用户知情"——必须在对话中显式汇报。
