# 参考资料导航

本目录采用渐进式加载。先确定当前阶段，只读取对应角色入口；遇到具体任务再读取一份或少量参考文件。

> **课件优先（全局规则）**：模型使用及论文写作的学习资源，**优先参考 `课件/`（源 `E:\数模\课件\`）**；不同资料的模型术语、模型步骤等若有冲突，**一律以课件为准**（用户对该课件有学习记忆和依赖）。课件索引与按任务加载表见 `课件/README.md`。

## 根目录

- `SKILL_ROOT`：本仓库根目录，只读。
- `PROJECT_ROOT`：用户项目目录，所有产物写入这里。

任何参考文档中的相对路径均以其所属 `SKILL.md` 目录为基准。角色文档通过 `../../..` 回到 `SKILL_ROOT`。

## 课件资料（学习资源，第一优先）

本队备赛课件（源文件：`E:\数模\课件\`，同步于此；每个 docx 均有同名 `.md` 提取版供检索），**模型使用及论文写作的学习资源优先参考本目录，冲突以课件为准**（详见 `课件/README.md` 的课件优先规则与按任务加载表）。分类与源一致：

- `课件/论文写作.md`：论文写作团队标准（摘要 300-400 字五要素、结构黄金模板与篇幅分配、模型阐述与结果展示要点），**论文写作阶段必读**。
- `课件/数据处理与预测模型/`（2026-08 新增分类）：`1数据预处理理论基础.md`（清洗流水线/缺失异常重复处理/插值/线性回归/灰色预测选型，含真题答案与完整代码）、`2ARIMA&SARIMA时间序列模型零基础全解.md`（ARIMA 国赛 7 步流程/ADF/ACF-PACF 定参/残差检验/SARIMA 季节参数/选型对比/满分话术）。
- `课件/优化模型与评价模型/`（2026-08 新分类）：`优化模型 + 评价模型.md`（优化三要素/LP/IP/0-1/MILP 与评价选型总览）、`AHP.md`、`TOPSIS.md`、`bigM.md`、`PuLP代码.md`。
- `课件/CUMCM国赛案例与建模步骤.md`：赛题案例与模型分类（历年真题题型统计与经典题建模拆解）。
- `课件/数学建模竞赛备赛教案.md`：教案全文（含国一/省一论文差异分析）。
- `课件/数学建模新手备赛指南.md`、`课件/数模第一节课补充.md`、`课件/建模思维与流程.md`：入门与流程。
