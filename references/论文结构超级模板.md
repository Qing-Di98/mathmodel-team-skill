## 一、总体说明

- **章节命名规则（用户 2026-08-16 定稿）**：大章节名大部分按旧模板（`references/roles/论文手/references/论文模板.docx`）——**问题重述、模型假设、符号说明、问题×的模型建立与求解**，问题重述下的小节也按旧模板（**1.1 问题背景 / 1.2 问题重述** 两节）；其余章节按新模板（问题分析、模型的评价、改进与推广、参考文献、附录）；**与 mathmodel-team-skill 既有要求冲突时，以 skill 既有要求为第一准则**（如假设 5-6 条无参数、符号表三列格式等，见 `竞赛要求.md`、`模型假设和符号说明.md`）。
- 模板结构固定为十一个部分：标题 → 摘要 → 关键词 → 一、问题重述（1.1 问题背景 / 1.2 问题重述）→ 二、问题分析 → 三、模型假设 → 四、符号说明 → 五~七、问题×的模型建立与求解 → 八、模型的评价、改进与推广 → 九、参考文献 → 附录；删节需谨慎。**正文最后两章为模型的评价、改进与推广与参考文献；附录不是正文，不参与章节编号，另起一页（2026-08-18 用户指令）。**
- 模板自带样式（字体、标题层级、编号），**复制后只改内容，不重建样式**。
- 模板各节内嵌指导文字，替换正文时一并删去。

## 二、各节结构与写作要点

### 1. 标题

- 填空式：`基于XXX模型的XXX研究与分析`（核心模型 + 研究对象）。

### 2. 摘要（论文"门面"，通常决定读者是否继续阅读）

- **方法**：清晰描述主要方法/技术（深度学习、遗传算法、有限元分析等）。
- **问题解决**：描述论文解决的主要问题或挑战。
- **主要结果**：简洁介绍主要发现/结论，量化（如"模型预测准确率提高了 15%"）。
- **简练性**：避免冗余和不必要的描述，每句话都传达重要信息。
- **准确性**：摘要中的信息与正文内容**完全一致**，无误导性描述。
- 长度：内容丰富但**不超过一页**。
- （本队摘要规范仍优先：300-400 字、开头段三句、每问"方法→关键处理→求解→精确数值"——见 `摘要写作规范.md`。）

### 3. 关键词

- 通常 **3-8 个**，每个都有存在意义。
- 选词：反映文章核心内容 → 涵盖方法和技术 → 体现独特性和特色。
- **避免过于宽泛的词汇**（如"研究""方法"这类无指导意义的词）。

### 4. 问题重述（一、问题重述，下含两小节）

- **1.1 问题背景**：用简单明了的语言提供清晰背景——问题的来源和重要性；原始问题描述很短时适当展开，补充必要背景和解释。
- **1.2 问题重述**：**避免直接复制原题**，按问题复杂度适当拆分或精炼——原题很长/复杂时精炼核心内容；逐问概述（"对于问题一，……"）。
- 小节固定为 1.1/1.2 两节（用户 2026-08-16 定稿，不设 1.3）。

### 5. 问题分析（二、问题分析）

- **不复述问题背景**（背景已在问题重述 1.1 给出），**内容不与问题重述重叠**（用户 2026-08-16 定稿原则）。
- **在问题重述的基础上进行分析**：定性分析明确问题的核心难点和挑战，**提出参赛者独有的思考**（对题目的理解、切入点、取舍逻辑）。
- 为后续数学建模提供思路，**预判可能需要用到的方法和技巧**，为建模解题做铺垫。

### 6. 模型假设（三、模型假设，旧模板名）

- 每条假设简单明了、避免模糊描述；**每条都给出合理性解释或证据**（基于实际情境或已有知识）——对应新模板原"假设合理性分析及说明"节的写作要点。
- 假设制定应**针对模型的关键部分**，避免不必要或无关的假设。
- 两类典型合理性理由：①**小概率事件**忽略（如气象模型不考虑地震——概率小但对结果影响巨大）；②**难以计算或缺乏数据**的因素简化（如交通模型假设驾驶员驾驶习惯相同——不准确但必要）。
- （本队硬性要求仍优先：5-6 条、无数值/参数/实验内容、`**假设一**：假设……` 格式——见 `模型假设和符号说明.md`。）

### 7. 符号说明（四、符号说明，旧模板名）

- 三列表：**符号 / 定义 / 单位**（与本队符号表规范一致，无单位用 `-`）。
- 每个符号定义简单明了；**复杂或不常见符号提供详细解释**。
- **全篇文章对该符号的使用与此处定义保持一致**，避免混淆。

### 8. 问题×的模型建立与求解（五~七，旧模板大章节名，每问一章）

每问一个独立大节（问题一的模型建立与求解 / 问题二的… / 问题三的…，按题面数量增减），内部两小节同构：

**问题×的前期准备（小节一）四件套**：

1. **问题分析**：明确问题背景、目的和要求；区分主要问题和次要问题。
2. **数据收集与整理**：搜集历史数据/统计信息/实验数据；初步处理（去除异常值、标准化、归类）。
3. **理论知识与方法复习**：复习相关数学理论（线性代数、微积分、统计学、优化理论等）；熟悉工具（MATLAB、Python 等）。
4. **预先设想与策略**：对候选模型初步设想（线性模型、动态系统模型、概率模型等）；制定初步建模策略和求解方法。

**问题×的模型建立与求解（小节二）四步**：

1. **建模**：根据预设想明确模型类型；基于已有数据和知识明确变量、参数、约束；表达数学形式（方程、不等式、目标函数）。
2. **模型简化与假设**：按实际情况简化（忽略复杂因素、假设某些参数为常数）；列出所有假设并给合理性解释。
3. **模型求解**：选择合适方法（解析、数值、模拟）；用工具求解得初步结果。
4. **结果验证与分析**：验证结果与实际情况相符；根据结果给出答案或建议。

### 9. 模型的评价、改进与推广

**优点**（三角度）：明确性——列举模型处理问题的长处（如计算速度快）；对比——与其他常用方法对比突出相对优势；广泛性——能处理一系列相似问题。

**缺点**（三角度）：限制性——明确适用范围和条件；复杂性——需要大量计算资源或时间；精确性——某些情况下预测与实际存在偏差。

**改进**（三方向）：方法优化——其他技术/算法增强性能；增加复杂性——引入更多变量参数提高精确性；新技术引入——机器学习、深度学习等增强预测能力。

**推广**（三形式）：应用领域扩展——模型在其他领域的应用可能性；普适性——不同背景/环境下如何微调适应；实际应用案例——提供一两个成功案例增强说服力。

### 10. 参考文献

- **格式统一**：选一种标准格式（如 GB/T 7714）全部条目按此排列。
- **完整性**：列出所有引用的文献，不遗漏；**按引用顺序排列**。
- **准确性**：对每项文献的描述准确；**避免不可靠来源**，尽量引用权威可靠的资源。

### 11. 附录

- **组织结构**：用子标题、标号使内容易于理解。
- **清晰标注**：正文中提到的一切附录资料在附录中清晰标出（"详见附录 A"）。
- **避免冗余**：不插入与研究无关或不重要的内容。
- **格式统一**：附录图表、字体、排版与正文一致。
- **提供解释**：复杂数据或不常见方法给简短解释，帮助读者理解。

## 三、使用流程（Word 论文生成）

1. 复制 `<SKILL_ROOT>/tools/docx/templates/数学建模论文超级模板.docx` 到论文项目根目录。
2. **改文件名**（如 `论文.docx`），**不要重新生成 Word**——模板样式即最终样式。
3. 按上文各节要点替换内容（删去模板内嵌指导文字）。
4. 插图：按 5writing 图表规划插入；已排好版需换图时用 Word 原位替换（`tools/docx` 对应节，`wp:extent` 与 `a:ext` 同步）。
5. 完稿前逐节对照本指南 + `竞赛要求.md` 排版硬性细节，进 `stages/6verity` 校验。
