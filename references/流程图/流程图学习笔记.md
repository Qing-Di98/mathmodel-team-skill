> 分析方法：RapidOCR 文字定位（推断排版结构）+ PIL 像素采样（背景色、强调色、高对比色占比）。

## 二、逐张分析

### flow_2（绿灰系，Wordle 四问）
- **排版**：一级分隔用大号问题标签（Problem1~4，图四角各占一区）；每个问题区内部是纵向方法/指标块（ARIMA → LSTM → 线性/树/Stacking 模型逐层向下），块间由箭头连接。中轴有"1 try/2 tries/6 tries/X tries"的用户猜词路径。
- **颜色对比**：底 #E6EDDE 等浅绿（非白像素 58%），强调色灰青 #80C0C0、浅青绿 #A0E0C0，文字深灰 #606060。**亮度对比为主（浅底深字），饱和度刻意压低**，全部元素收敛在"绿"一个色相家族内。
- **美观度**：统一性极强，一眼看出"这是同一张图的四个区"；缺点是文字密集、块间区分度略弱。

### flow_3（灰白青系，DAS 五步）
- **排版**：之字形布局——上部左 Step1 评估 → 右 Step2 优化（含 xyz 三维坐标轴：People/Tech/Process 三性能维度）；下部从左侧 Step5 信件 → Step4 模型扩展 → 右端 Step3 协议，底部收在 "Optimizing Proposal"。完全靠 **Step 编号 + 箭头方向** 承载阅读顺序。
- **颜色对比**：几乎纯黑白灰（高对比色 47.7% 但其中 38% 是灰阶），仅青 #80E0E0 点缀 17%。**五张里颜色最收敛的一张**。
- **美观度**：风格最"论文级"，干净克制；代价是视觉记忆点少，完全依赖结构清晰度。

### flow_4（鲜绿系，光污染四任务）——最值得学色彩的一张
- **排版**：Task1（左上）/Task2（右上）/Task3（中右）/Task4（左下）四分区；左半是评估流程（Society/Ecology/Traffic/Energy 指标识别 → EWM → K-Means → 多因素 → 效果预测/策略），右半一列 4 个"Application in protected land / rural / urban / suburban community"应用场景块，形成**"方法 → 应用场景"双列对仗**。
- **颜色对比**：唯一大面积高饱和用色的图——鲜绿 #92D050 铺色块（高对比色中占 47%），配蓝紫 #A0A0E0、米黄 #E0E0A0，深蓝文字 #204080。高对比像素占比 68.5%，为五张之最。
- **美观度**：记忆点最强、分区最清晰（每个任务区色块边界肉眼可辨）；风险是鲜艳色多时容易"花"，此图靠**每区一个主色、背景仍留白 55.9%** 压住了。

### flow_5（米黄暖色系，词难度双模型）
- **排版**：左右两大块。左侧 GPU 预测模型（reset gate / update gate → GPU model → output 的循环单元结构，下接 Grid Search → Best params → Random Forest）；右侧"词属性与分数关系"四指标横向并排（Word Frequency / Letter Frequency / Repetition / Part of Speech → 回归分析 + 箱线分析），右端"Interesting Features"（Hard Mode 百分比、EERIE 难度分类、K-Means++ 聚类）。
- **颜色对比**：浅米黄底 #FFFAE7，点缀黄绿 #A0C080、橙 #E08040、黄褐 #C0A040、粉红 #E0A0A0——**唯一暖色多色系**；标题行有明显字号层级（大标题 vs input/output 小标签）。
- **美观度**：暖色调亲和力强；多色点缀让各子分析块易区分；底色铺得最满（白底仅 26.5%），信息密度最高。

### flow_6（蓝紫灰系）——与 flow_2 的对照结论
- 排版、文字、区块布局与 flow_2 **完全相同**，只换了配色：浅蓝 #D7E4F1 / 浅紫 #E2DFF0 底，灰蓝 #8080A0 / 深灰蓝 #606080 强调。
- 实测对比：flow_2 高对比像素 27.8%，flow_6 仅 21.2%——**绿色系比蓝紫系更"跳"、更醒目**；蓝紫系更冷静、更"商务"。
- **结论**：同一张流程图，观感温度与记忆度主要由配色决定；排版功底决定"清不清楚"，配色决定"记不记得住"。

## 三、共性要素提炼（可复用的流程图制作规范）

1. **编号是第一级导航**：五张全部用 Problem/Task/Step 大标签分区，读者先看编号定位、再看区内内容。自己的流程图先定"几问/几步"，再画内容。
2. **一张图一个主色相家族**：色块/箭头/强调线收敛在同一色相（绿、蓝紫、米黄、灰青），背景一律极浅色（接近白），文字深灰 #606060 级。只有 flow_4 用大面积高饱和色，那是"活泼"风格的刻意选择，代价是必须留白更多（55.9%）。
3. **对比层次三档**：标题（大号深色）> 块内文字（中号）> 解释小字（小号灰色）。亮度对比为主、饱和度对比为辅。
4. **文字用短标签**：块内只放方法名/指标名（"ARIMA model"、"EWM"、"K-Means"），长解释拆成小字或省略——流程图是索引，不是正文。
5. **结构对仗加分**：flow_4 的"方法 → 四应用场景"、flow_5 的"左模型右分析"都用了成列对仗，比单流向图信息密度高得多。
6. **形状语言统一**：圆角矩形色块 + 箭头 + 编号徽标，三种元素走天下；flow_3 证明黑白灰 + 结构清晰也可以很专业。

## 四、反例对照（2019 简化版论文旧流程图）

> 分析对象：`E:\数模\往年题\2019\C-2019中文\04_论文\figures\` 下 fig_flow_q1q2/q3/q4.png（2872×1612，纯白底线条图）。
> 用户评价："做的很不好"，本队流程图标准应参照 flow_2~6 模板。

**旧图客观特征（量化）**：非底色像素仅 15.0%~17.3%——整图纯白底、**无任何色块填充系统**；布局为三层×三列对称（标题居中 + 每层三个并排框），OCR 显示文字全部是参数/公式/数值（rB=(rcH−ceDe)/(Te+H)、W*=124.41 min、α*=0.1）。

**与模板的差距（对照 flow_2~6）**：

| 维度 | 旧图（2019） | 模板（flow_2~6） |
|---|---|---|
| 底色 | 纯白，无分区色块 | 每区一块浅色（#E6EDDE/#D0EFE7 级），块感明确 |
| 配色 | 零彩色 | 一个主色相家族 + 深灰文字 |
| 编号导航 | 只有整图标题"Q1/Q2：…" | Problem/Task/Step 大标签分区 |
| 文字 | 框内塞公式与参数（每框 2-4 行） | 短标签（方法名/指标名），长内容拆小字 |
| 层级 | 无字号层级 | 标题 > 块内文字 > 小字注释 三档 |
| 观感 | 逻辑对但"草稿感"，视觉平 | 分区明确、一眼可扫 |

**教训（本队流程图最低标准）**：流程图不是"把文字放进框里画箭头"——内容正确只是及格线；**浅色分区块 + 一个主色相 + 编号导航 + 短标签**是必须项。评审最先看的是图，配色分区是"半小时投入、观感翻倍"的投资。

## 五、如果要在自己的论文里复刻

- 画法：PPT 形状/draw.io——圆角矩形（浅色填充 + 同色相描边）+ 直角箭头 + 编号圆点，导出 PNG 前统一放大字体、压缩空白边距。
- 默认配色建议抄 flow_2 的绿系（温和醒目平衡）或 flow_3 的灰青系（论文级克制）；要活泼再考虑 flow_4 的鲜绿大色块。
- 检查清单：编号是否连续可读？每块是否只有一个短标签？背景是否留白足够？文字是否有三档层级？
